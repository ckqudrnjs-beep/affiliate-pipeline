# 쇼츠 기획 (우리 채널 전용)

이 저장소의 쇼츠 기획·대본·주간 점검은 이 순서로 한다. 아래 **우리 규칙**이 viral-* 스킬(영어 일반론)보다 항상 우선이다.

## 0. 먼저 읽을 것 (있는 것만)
1. `docs/SHORTS_GROWTH.md` — 규칙 원본 (주부 타깃, 동전이, 형식 3개, 구독 한 줄, 판단 기준)
2. `docs/SHORTS_WEEKLY.md` — 우리 영상 조회수·평균 시청 비율·공유 (매일 22:41 수집)
3. `docs/SHORTS_TRENDS_WEEKLY.md` — 지난 7일 한국 쇼츠 키워드별 상위 (매주 월 06:50, `pipeline.trend_radar`)
4. 숫자 근거: `data/daily/` 최신 시세, 사이트 페이지(calc/·q/·guide/·recipe/·report)

## 1. 우리 규칙 (어기면 안 됨)
- **돈 줍는 삼촌**: 보는 사람 = 장보기·살림 맡은 30~50대 주부. 상품·제휴·특가 없음. 하루 1편 19:00. 사이트 정보 페이지 1개로 연결.
- **아하 1개 필수**: 흔한 믿음을 사이트 숫자로 뒤집는다. 사이트에 근거 없는 숫자·아하 금지 (트렌드 표·남의 영상 숫자 사용 금지).
- **첫 1초 = 큰 숫자 비교 훅**: 첫 장면 badge(숫자+물음표) 필수 (`episodes.check`가 강제).
- 형식은 3개: 장바구니 시세 / 살림 상황극(동전이) / "1년이면 얼마?" 카드. 요일표는 `episodes.SHORT_FORMATS`.
- 구독·즐겨찾기는 끝에 한 번, 이유와 함께. 보상 약속·화면 고정 문구 금지 (유튜브 정책).
- **5락실**: 게임 화면·밸런스 질문. 코인·보상은 게임 안에서만 무료 획득. 끝 문구는 `docs/SHORTS_GROWTH.md` 표대로.
- AI 표기, 낚시 제목(내용에 없는 약속) 금지, 남의 제목·대사·영상 베끼기 금지.

## 2. 주제 고르기
1. 트렌드 표에서 **우리 사이트 숫자로 답할 수 있는** 키워드만 고른다 (예: "김장 비용"이 뜨면 → 배추·무 시세 아하).
2. `viral-short-form-ideas` 의 기둥(pillar)·각도 나누기로 한 주제를 3~5개 각도로 쪼갠다. 기둥 = 장바구니 / 전기·가스·난방 / 집밥 원가 / 관리비.
3. 지난주 `SHORTS_WEEKLY.md` 상위 형식과 겹치면 우선, 2주 연속 꼴찌 형식은 피한다.

## 3. 훅·대본
- `viral-hooks` 로 훅 후보 5개를 만들고, 그중 **숫자 비교형**(예: "밥솥 보온, 1년이면 8만 9천 원?")을 고른다. 트렌드 표의 "훅 분포"에서 많이 쓰인 유형을 참고만 한다.
- `viral-youtube-shorts` 의 길이·루프·2~3초 안 반전 원칙: 우리 기준은 내레이션 110~240자(약 18~33초), 끝 장면이 첫 장면으로 이어지게.
- 원문의 "롱폼으로 보내라"는 무시 (롱폼 중단). 대신 사이트 페이지 1개.
- 대본 형식(skit 줄, pet, pet_say, badge 등)은 `docs/EPISODES.md`·`episodes.HOME_RULE` 을 따른다.

## 4. 제목·설명·자막
- `viral-captions-and-ctas` 로 첫 줄(40자 이하 핵심)·해시태그 3개·고정 댓글 후보를 만든다. 해시태그는 SHORTS_GROWTH 표(#장보기 #물가 / #살림 #전기요금 / #살림 #절약).
- 참여 낚시("댓글에 1 남기면 …") 금지.

## 5. 올리기 전 확인
- `watch` 스킬(local 엔진, 키 없음)로 렌더된 mp4 프레임을 보고 글자 잘림·안전 영역·첫 프레임 숫자를 확인한다.

## 6. 주간 점검 (월 10:23 트리거)
- `SHORTS_WEEKLY.md`(우리 성적) + `SHORTS_TRENDS_WEEKLY.md`(시장) 를 같이 보고, 바꿀 것 1~3개만 `docs/SHORTS_GROWTH.md` 에 날짜와 함께 적는다. BK 보고는 7일 중간 보고에 묶는다.
