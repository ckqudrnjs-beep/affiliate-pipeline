## 링크 자동 생성: 되는 것과 안 되는 것 (2026-11-07)
| 프로그램 | 자동화 | 방법 | 이유 |
|---|---|---|---|
| 쿠팡 | 최종 승인 후 **자동** | Open API (골드박스·검색·딥링크) | 승인 전 사이트 크롤링·자동 로그인은 약관 위반 위험 → 하지 않음 |
| 알리익스프레스 | **지금 바로 자동** | 공식 Affiliate API (인기상품 조회 결과에 제휴 링크 포함) | Portals 가입 + 앱 키 신청만 필요, 판매 실적 조건 언급 없음(제3자 자료, *확인 필요*) |
| 네이버 브랜드 커넥트 | **수동** | 사이트에서 직접 발급 | 공식 API 확인 안 됨. 브라우저 자동화 사례가 있으나 네이버는 자동 프로그램 사용을 제한 → 계정 위험 |
| 링크프라이스 | 확인 필요 | 로그인 후 API/딥링크 메뉴 확인 | 공개 자료 부족 |

## 가입 현황 (2026-11-07)
- 쿠팡 파트너스: 가입, **최종 승인 대기**
- 네이버 브랜드 커넥트(쇼핑 커넥트): **가입 완료**. 쿠팡 최종 승인과 무관하게 바로 링크 사용 가능 → 초기 수익원으로 병행
- 나머지(알리·링크프라이스·삼성): 사용자 확인 필요

## 네이버 브랜드 커넥트 운영 메모
- 링크는 브랜드 커넥트에서 상품별로 직접 생성해 `config/products.csv`에 `program=naver`로 입력.
- 링크 도메인(naver.me 등)은 실제 생성 링크로 확인 후 검사기 허용 목록 조정 (*확인 필요*).
- 대가성 문구: "이 포스팅은 네이버 쇼핑 커넥트(브랜드 커넥트) 활동의 일환으로, 판매 발생 시 일정액의 수수료를 제공받습니다."
- 스마트스토어 상품 위주라 쿠팡과 겹치지 않는 상품(브랜드 단독, 공동구매) 발굴에 유리.

## 쿠팡 최종 승인 (2026-11-07 조사)
- 가입 승인만으로는 정산·Open API가 열리지 않고, **누적 판매 15만 원**을 넘기면 최종 승인 심사가 진행된다는 설명이 있음 (비공식 블로그 근거, *공식 가이드 확인 필요*).
- 반려 사유로 콘텐츠 수 부족, 대가성 문구 누락, 금지 콘텐츠가 언급됨.
- **파트너스 사이트에 등록하지 않은 채널(SNS 계정·블로그)로 홍보하면 부정행위로 간주**될 수 있음 → 쓰는 채널 URL을 모두 등록.
- 본인 구매·지인에게 구매 부탁은 하지 않는다 (약관상 부정 실적 위험).

## 공통 원칙
- 링크는 각 사 공식 링크 생성기 또는 공식 API로만 만든다. 링크 위장·리다이렉트 숨김·쿠키 강제 삽입(쿠키 스터핑) 금지.
- 자기 구매·지인 구매 유도, 리워드/포인트 지급 대가 클릭 유도 금지 (대부분 약관 위반).
- API 키는 GitHub Secrets 등에만 저장. 사용자 직접 입력.
- 정산 정보(계좌·신분증)는 사용자 직접 처리.

## 가입 순서 제안
1. 쿠팡 파트너스 — 가장 범용, 승인 기준 충족 위해 사이트/채널 먼저 준비
