## 공통 원칙
- 링크는 각 사 공식 링크 생성기 또는 공식 API로만 만든다. 링크 위장·리다이렉트 숨김·쿠키 강제 삽입(쿠키 스터핑) 금지.
- 자기 구매·지인 구매 유도, 리워드/포인트 지급 대가 클릭 유도 금지 (대부분 약관 위반).
- API 키는 GitHub Secrets 등에만 저장. 사용자 직접 입력.
- 정산 정보(계좌·신분증)는 사용자 직접 처리.

## 가입 순서 제안
1. 쿠팡 파트너스 — 가장 범용, 승인 기준 충족 위해 사이트/채널 먼저 준비
2. 링크프라이스 — 삼성 등 브랜드 광고주 확인
3. 알리 Portals — 해외직구 저가 트렌드 상품
4. 네이버 브랜드 커넥트 — 블로그/인플루언서 자격 확인
5. 삼성전자 — 링크프라이스 등 경유 가능 여부 확인 후
