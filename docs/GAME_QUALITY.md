# 5락실 게임 그래픽 품질 기준 (GAME_QUALITY.md)

> 최초 작성 2026-11-14 (BK: "네온 생존자 대비 디자인이 떨어지는 게임 개선, 앞으로 게임도 품질 신경"). 기준 게임 = **네온 생존자**(/games/survivor).
> 새 게임은 PR 올리기 전에 아래 체크리스트를 통과해야 하고, PR 본문에 체크 결과와 휴대폰·PC 스크린샷을 붙인다.

## 1. 필수 체크리스트 (10개 중 9개 이상 = 통과)
1. **첫 화면 포스터**: 페이지에 빈 캔버스·회색 상자 대신 실제 게임 그림 포스터(16:9, `static/img/<slug>-poster.jpg`) + 노란 ▶ 시작 버튼. 공유 이미지(og)도 같은 포스터.
2. **전체 화면 플레이**: 시작하면 전체 화면 오버레이(아이폰은 화면 꽉 찬 오버레이), meta.json `"ownfs": true`. 오른쪽 위 🔊 Ⅱ ✕ 버튼.
3. **배경에 깊이**: 단색 금지. 그라데이션 + 성운/빛 번짐 + 움직이는 2겹 이상(별·입자·격자). 가로 화면 양옆 빈 공간도 꾸밈.
4. **주인공·적·아이템은 코드로 그린 그림**: 이모지·기본 도형(단색 원·사각형)만으로 된 캐릭터 금지. 그라데이션·하이라이트·외곽 빛. 상점 스킨도 같은 품질로 직접 그림.
5. **네온 빛**: 중요한 물체에 빛(glow) — `shadowBlur` 대신 미리 그린 빛 스프라이트 + `lighter` 합성(성능).
6. **손맛(juice)**: 맞힘·획득·죽음마다 입자, 떠오르는 점수 글자, 고리 파동, 화면 흔들림/번쩍임 중 최소 3가지.
7. **소리**: 웹오디오 합성 효과음 4종 이상 + 배경음(끄기 버튼, 설정 기억).
8. **HUD**: 점수·시간·단계를 픽셀 글꼴(Press Start 2P)로, 제목·안내는 Black Han Sans. 처음 3초 조작 안내.
9. **결과 화면**: 점수 크게, NEW BEST, 기록 3칸(시간·수집·특기), 다시 도전(Enter)·결과 공유·이 게임 상점·나가기.
10. **성능·공정성**: 픽셀 비율 최대 2·화면 픽셀 360만 상한, 스프라이트 미리 그림, 고정 프레임(1/60) 업데이트. 경기장 넓이는 기기와 상관없이 같게. 멈춤 한 판 1번 + 3초 카운트다운(자동 멈춤 무료).

## 2. 권장
- 단계가 오르면 배경음 빨라짐·"SPEED UP" 같은 연출.
- 디버그 `#<slug>debug` → `window.__xx` (bot, fast, god, poster) — 쇼츠 녹화·포스터 제작용.
- 포스터는 디버그 `poster()`로 게임 그림 그대로 1280×720 캡처.

## 3. 금지
- 특정 기존 게임의 이름·캐릭터·그림·음악 따라 하기, 외부 이미지·음원 파일.
- 사진(BK 11/14 틀린그림 결정).
- 판정·점수를 바꾸는 꾸미기(꾸미기는 겉모습만).
