- 기준가는 2026-11-13 대형마트·온라인 장보기 흔한 가격대 추정치(쿠팡 가격 수집 아님). 페이지에 "대략"·날짜 표기. 분기마다 한 번 점검.
- 연말 홈파티 (2026-11-14): `data/recipes/party-*.json` 5개(감바스·밀푀유나베·에어프라이어 간장 닭봉·로제 떡볶이·쏘야). `"serves": 4`, `"collection": "party"`, `"deliveryNote"`(배달 대략가 근거). 재료 양·배달가는 4인분 기준이고 원가 표는 4인분 합계, 1인분 = 합계 ÷ 4. 목록 맨 위 "연말 홈파티 레시피 (4인 기준)" 칸에 4명 한 상 예시(`recipes.PARTY_SET`, 배달비는 한 번만)를 보여 준다. 레시피 페이지에 "왜 이 값인가요?"(배달 근거)와 가장 비싼 재료 비중을 적는다. 기준가에 재료 15개 추가(가격은 11/14 추정, 쿠팡 가격 아님). 오늘의 얼마게 문제도 4인분 기준으로 자동 생성.
- 쿠팡 재료 링크: BK님이 파트너스에서 만든 링크를 `config/recipe_pantry.csv`의 `coupangUrl`에 넣는다. 링크 있는 재료만 "재료 한 번에 장보기" 칸에 나오고, 하나도 없으면 칸 자체가 숨는다. 칸 안에 쿠팡 공식 대가성 문구 그대로, `rel="sponsored nofollow"`, 쿠팡 이미지·쿠팡 가격 표시 없음. 허용 도메인 외 링크는 빌드 실패.
- 링크 우선순위(여러 레시피에 쓰고 오래 두는 재료 15개): 쌀, 계란, 식용유, 고춧가루, 진간장, 설탕, 참기름, 고추장, 된장, 코인 육수, 포기김치, 냉동 볶음밥 채소, 참치캔, 카레 가루, 떡볶이 떡.
