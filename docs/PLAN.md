## 1. 목표

- 본업 외 부업으로 **월 1,000만 원** 제휴 수수료 수익.
- 사람이 매일 손대지 않아도 돌아가는 **사후관리 최소 구조** (주 1~2시간 점검 목표).
- 대상 프로그램: 쿠팡 파트너스, 네이버(쇼핑 커넥트/브랜드 커넥트), 삼성전자, 알리익스프레스(Portals), 링크프라이스.
- 채널: 블로그/자체 웹사이트, 유튜브(롱폼·쇼츠), 인스타그램, 스레드, 기타 SNS.
- 원칙: 플랫폼 약관과 공정위 「추천·보증 심사지침」을 **항상** 지킨다. 스팸·어뷰징 자동화는 하지 않는다.

## 2. 현실적인 수익성 판단 (솔직하게)

월 1,000만 원은 가능하지만 **상위 극소수 수준**입니다. 숫자로 보면 이렇습니다.

| 가정 평균 수수료율 | 월 1,000만 원에 필요한 월 거래액(GMV) |
|---|---|
| 3% (쿠팡 일반 상품 수준, *확인 필요*) | 약 3억 3천만 원 |
| 5% (알리·링크프라이스 일부 광고주 혼합) | 약 2억 원 |
| 8% (고수수료 카테고리 위주) | 약 1억 2,500만 원 |

- 구매 전환율 2~4%, 객단가 5만 원으로 잡으면 월 **수십만~백만 건 이상의 클릭**이 필요합니다.
- 따라서 "자동 글 대량 발행"으로는 도달할 수 없고(플랫폼이 저품질 반복 콘텐츠를 걸러냄), **검색 유입이 쌓이는 자산형 채널(블로그·유튜브) + 트렌드형 단기 채널(SNS)** 조합이 필요합니다.
- 현실적 경로 예시: 3개월차 월 10만~50만 원 → 6개월차 100만~300만 원 → 12~24개월차 500만~1,000만 원. 이 수치는 업계 사례 기반의 **추정치**이며 보장되지 않습니다.
- "사후관리가 전혀 없는" 구조는 불가능합니다. 정책 변경·링크 만료·품절 상품 교체 때문에 **주간 점검**은 남습니다. 목표는 이 점검을 대시보드 확인 수준으로 줄이는 것입니다.

## 3. 전체 구조

```
[트렌드 수집] → [상품 매칭] → [콘텐츠 생성] → [사람 검수(초기)] → [채널 발행] → [성과 수집] → [개선]
   네이버 데이터랩    각 제휴 API로     AI 초안 +          승인 큐          공식 API만 사용     제휴사 리포트
   구글 트렌드        딥링크 생성       실제 정보(가격·스펙)  (점차 자동 승인)   (블로그/YT/IG/Threads) + UTM/단축링크
   쿠팡 베스트 등     수수료율 비교      대가성 문구 자동 삽입                                      → 주간 리포트
```

- 실행 환경 후보: GitHub Actions 크론(무료) + 정적 사이트(GitHub Pages/Cloudflare Pages, 무료) + 스프레드시트 또는 SQLite 기록.
- 비밀값(API 키): GitHub Secrets 등 비밀 저장소에만 둔다. 채팅·파일에 평문 금지. 연결은 사용자가 직접.

## 4. 단계별 로드맵

### Phase 0 — 설계·가입 (1~2주, 지금)
- [ ] 근본 설계 질문 답변 받기 → [DECISIONS.md](DECISIONS.md)
- [ ] 제휴 프로그램 가입·승인 (사용자 직접): 쿠팡 파트너스 → 링크프라이스 → 알리 Portals → 네이버 → 삼성(경로 확인)
- [ ] 사업자등록·세금 처리 방식 결정
- [ ] 주력 니치(카테고리) 2~3개 선정
- [ ] GitHub 저장소 생성 여부 결정 (생성·푸시는 사용자 확인 후)

### Phase 1 — 자산형 채널 MVP (2~6주)
- [ ] 정적 사이트(비교·리뷰·가이드형) 구축, 대가성 문구 템플릿 내장
- [ ] 쿠팡/알리/링크프라이스 API 연동으로 상품 데이터·딥링크 자동 생성
- [ ] 주 3~5편 "실제로 도움 되는" 글 (사람 검수 후 발행)
- [ ] 클릭·수익 기록 스프레드시트/DB

### Phase 2 — 유튜브·SNS 확장 (2~4개월)
- [ ] 유튜브 쇼츠/롱폼 포맷 결정(얼굴·목소리 여부에 따라) → 유튜브 쇼핑 제휴(알리 포함, 한국 2026-03 도입 보도) 검토
- [ ] 인스타그램·스레드 공식 API로 예약 발행 (트렌드 상품 카드뉴스)
- [ ] 콘텐츠 1개 → 블로그·쇼츠·카드뉴스 재활용 파이프라인

### Phase 3 — 자동화 고도화 (4~8개월)
- [ ] 검수 기준 충족 시 자동 승인 범위 확대 (단, 대가성 문구·사실 확인은 자동 검사 필수)
- [ ] 품절·가격변동 감지 후 글 자동 갱신
- [ ] 성과 기반 카테고리/채널 예산 재배분

### Phase 4 — 확장 (8~24개월)
- [ ] 성과 좋은 니치로 사이트·채널 추가
- [ ] 네이버 브랜드 커넥트 공동구매 등 고단가 협업
- [ ] 필요 시 외주(편집자·성우) 투입해 사람 작업 최소화
