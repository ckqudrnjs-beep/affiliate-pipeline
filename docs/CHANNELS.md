# 채널 전략 (CHANNELS.md)

> 최종 갱신: 2026-11-07

## 채널별 역할

| 채널 | 역할 | 자동 발행 방법 | 핵심 정책 리스크 |
|---|---|---|---|
| 자체 정적 사이트 (GitHub Pages/Cloudflare Pages) | **핵심 자산**. 검색 유입, 비교·가이드 글 | Git 커밋 → 자동 빌드 (완전 자동화 가능) | 거의 없음. 구글 "스팸 정책"(대량 저품질) 주의 |
| 네이버 블로그 | 국내 검색 유입 | 공식 글쓰기 API 제공 여부 *확인 필요* (중단된 것으로 알려짐) → 초안 자동 생성 + 사람이 붙여넣기 | 매크로 발행·자동 프로그램 금지, 저품질 판정 |
| 티스토리/워드프레스 | 보조 블로그 | 워드프레스 REST API 가능, 티스토리 API는 *확인 필요* | 동일 |
| 유튜브 쇼츠/롱폼 | 대량 노출, 유튜브 쇼핑 제휴 | YouTube Data API 업로드(쿼터 제한) | **반복·템플릿형 콘텐츠 수익화 제외**, AI 사용 시 합성 콘텐츠 표시 |
| 인스타그램 | 트렌드 상품 카드뉴스·릴스 | Instagram Graph API (프로페셔널 계정 필요) | 캡션 링크 불가 → 프로필 링크/스토리. 대가성 표기 첫 줄 |
| 스레드 | 텍스트 트렌드 | Threads API | 동일 |
| X / 페이스북 등 | 보조 | X API는 유료 | 반복 게시 스팸 판정 |

## 콘텐츠 원칙
1. **하나의 리서치 → 여러 포맷**: 비교 글 1편 → 쇼츠 1~3개 → 카드뉴스 1개 → 스레드 글 2개.
2. 실제 정보(가격·스펙·후기 요약·장단점)를 담는다. 상품 링크만 나열하는 글 금지.
3. 직접 써보지 않은 상품은 "사용 후기"처럼 쓰지 않는다 (기만 광고). "정리/비교" 형식으로.
4. 모든 콘텐츠 첫 부분에 대가성 문구 → [COMPLIANCE.md](COMPLIANCE.md).
5. 계정당 하루 발행량은 사람이 운영하는 수준으로 제한 (스팸 판정 방지).

## 결정: 유튜브는 C (AI 음성 + 자료 화면), 2026-11-07
- 영상마다 고유한 비교 기준·데이터(가격 추이, 스펙 표, 장단점)를 넣어 "반복 템플릿"으로 보이지 않게 한다.
- 사실적 AI 합성 요소가 있으면 업로드 시 합성 콘텐츠 표시.
- 대가성: 영상 시작 자막 + 설명란 첫 줄.
- 우선순위: 1) 스레드·인스타(빠른 클릭) 2) 기존 블로그 3) 쇼츠 4) 정적 사이트.

## 유튜브 포맷 선택지 (참고)
- A. 얼굴·목소리 출연: 신뢰도·전환율 최고, 시간 많이 듦
- B. 목소리만 + 화면/제품 영상: 균형형
- C. AI 음성 + 자료 화면: 시간 최소, 단 **반복 템플릿으로 보이면 수익화·노출 불이익** → 매 영상 고유한 비교·분석 필수
