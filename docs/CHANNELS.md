## 콘텐츠 원칙
1. **하나의 리서치 → 여러 포맷**: 비교 글 1편 → 쇼츠 1~3개 → 카드뉴스 1개 → 스레드 글 2개.
2. 실제 정보(가격·스펙·후기 요약·장단점)를 담는다. 상품 링크만 나열하는 글 금지.
3. 직접 써보지 않은 상품은 "사용 후기"처럼 쓰지 않는다 (기만 광고). "정리/비교" 형식으로.
4. 모든 콘텐츠 첫 부분에 대가성 문구 → [COMPLIANCE.md](COMPLIANCE.md).
5. 계정당 하루 발행량은 사람이 운영하는 수준으로 제한 (스팸 판정 방지).

## 결정: 유튜브는 C (AI 음성 + 자료 화면), 2026-11-07
- 영상마다 고유한 비교 기준·데이터(가격 추이, 스펙 표, 장단점)를 넣어 "반복 템플릿"으로 보이지 않게 한다.
- 사실적 AI 합성 요소가 있으면 업로드 시 합성 콘텐츠 표시.
- 대가성: 영상 시작 자막 + 설명란 첫 줄.
- 우선순위: 1) 스레드·인스타(빠른 클릭) 2) 기존 블로그 3) 쇼츠 4) 정적 사이트.

- 두 채널 모두 연결. 스레드는 텍스트라 바로 가능, 인스타는 이미지 필수라 이미지가 있는 초안만 올린다.
- 하루 4번(09:00·12:30·18:30·21:00 KST) 실행, 실행당 채널별 1개, 같은 문구 재게시 금지.
- 연결 절차·토큰: [META_SETUP.md](META_SETUP.md). 사용자가 `PUBLISH_ENABLED=true`를 켜야 실제 발행.
- 다음 과제: 인스타용 카드 이미지 자동 생성, 프로필 링크용 "오늘의 특가" 페이지(정적 사이트).

## 인스타·스레드의 수익 구조 (2026-11-07)

**플랫폼이 직접 주는 돈은 한국에선 사실상 없다고 보고 계획한다.** 스레드 보너스, 인스타 릴스 보너스·구독·선물 같은 크리에이터 보상은 초대제이거나 국가·자격 제한이 있다. 자격이 생기면 앱의 프로페셔널 대시보드에 뜨므로 그때 검토한다. 돈은 아래 경로로 번다.

| 단계 | 스레드 | 인스타그램 |
|---|---|---|
| 지금 (팔로워 0~1천) | **본문 링크로 직접 매출.** 홍보 글 첫 줄 대가성 문구 + 제휴 링크. 정보 글로 도달을 키우고 홍보 글은 절반 이하 | **직접 매출은 작다** (캡션 링크 클릭 불가). 저장·공유로 팔로워를 모으는 게 일. 프로필 링크(링크 모음·블로그), 스토리 링크 스티커로 보낸다 |
| 성장 (1천~1만) | 같은 구조 + 블로그·유튜브 비교 글로 보내는 링크 | 스토리 링크 스티커 전환이 커짐. "살까 말까 저울" 글 → 프로필 링크의 비교 페이지 |
| 이후 (1만+) | 브랜드 협찬·네이버 브랜드커넥트 캠페인 | 협찬 게시물(유료 파트너십 표시 필수), 브랜드커넥트·공동구매 |

- 핵심 지표: 스레드는 링크 클릭·제휴 매출, 인스타는 저장·공유·팔로워 증가 (매출은 프로필 링크·스토리 클릭으로 측정).
- 협찬은 대가성 표기와 플랫폼의 유료 파트너십 표시를 둘 다 한다 (COMPLIANCE.md).
