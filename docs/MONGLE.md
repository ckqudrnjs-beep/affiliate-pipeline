## 핵심
- 주인공: 숲 정령 **몽글이**(찹쌀떡 몸 + 머리 새싹). 전투 없음, 하루 5분 돌보기.
- 하루 루프: 돌보기(쓰다듬기·밥) → **오늘의 산책**(30분/2시간/6시간, 실제 시간, 하루 3번, 화면 꺼도 진행) → 재료·엽서 받기 → **요리**(재료 3개 조합 → 산책 보상·기분 버프) → 도토리로 가구 사서 **아지트 꾸미기** → 경험치로 성장.
- 성장: 씨앗(Lv1) → 새싹(Lv2) → 꼬마(Lv5) → 어른(Lv12) 3갈래: 든든 도토리(산책) / 반짝 별꽃(도감) / 포근 하트(돌보기).
- 도감: 재료·요리·엽서·숲 친구.
- 남에게 보이기: 아지트 구경(테스터끼리), 몽글이 색·모자·목도리.

## 재화 규칙
- 도토리 = 게임 안 돈(산책·요리로 벌기). 5락실 코인 1개 → 도토리 100, 하루 5개까지(네온 레이드 골드 교환과 같은 규칙).
- 몽글이 색 바꾸기 등 과시용은 5락실 코인. 현금 구매·거래·현금화·뽑기 없음.

## 체험판(테스터 전용)
- 네온 레이드가 만든 잠금 재사용: POST /api/profile {a:"tester"}, static/js/tester.js `nrTester()`, meta.json `"hidden": true`(홈·순위·사이트맵·검색·NEW GAME 쇼츠 제외, noindex).
- 체험판 저장은 기기(localStorage). 정식 때 프로필 저장 연결.

## 구현 (체험판 v1)
- 파일: playground/games/mongle/(meta.json hidden·ownfs, body.html, game.js) + static/js/mongle-art.js(그림) + static/js/mongle.js(게임) + static/img/mongle-poster.jpg.
- 화면 5개(아지트·산책·요리·도감·성장), 세로 390×844 기준, PC는 가운데 + 양옆 숲 장식. 전체 화면, 🔊·✕.
