# 5락실 홍보 계획 (2026-11-13, BK 요청 "오락실 사이트를 어떻게 홍보해야 하나")

사이트: https://5raksil.com
핵심 생각: 5락실은 **검색보다 "공유"로 크는 사이트**다. 밸런스게임·순위·친구 도전은 사람이 사람에게 보내야 퍼진다.
그래서 순서는 ① 공유가 잘 되게 → ② 매일 보여줄 콘텐츠를 자동으로 → ③ 검색 입구 → ④ 커뮤니티는 손으로 조금.

## 0. 현실 숫자 (추정, 보장 아님)
- 하루 15만 방문(30M 목표)은 대형 커뮤니티급. 1개월 현실치는 하루 50~500.
- 공유형 사이트는 "한 판이 터지면" 급증한다. 그래서 매일 공유될 거리를 꾸준히 만드는 게 전부.
- 측정 지표: 방문당 공유 횟수(K값). 0.3 이상이면 자연 확산이 붙기 시작.

## 8. 게임 밈 기획 (2026-11-13 BK: 로블록스·마크·포트나이트·배그 밈으로 홍보, 저작권 문제 없게)

| 해도 됨 (자동) | 하면 안 됨 |
|---|---|
| 밸런스 질문 주제: "마크 서바이벌 1년 vs 로블록스 타이쿤 1년" | 게임 캐릭터·로고·스크린샷·플레이 영상·음악·효과음 |
| 초성퀴즈 '게임 용어' (레벨업·리스폰·자기장·파밍…) — 추가함 | 비슷하게 따라 그린 캐릭터(블록 사람, 특정 스킨 등) |
| 누구 것도 아닌 밈 형식: "너라면?", "3초 안에 골라", 랭킹 도전 | 게임 속 고유 대사·슬로건 그대로 쓰기 |
| 쇼츠 제목·해시태그에 그 게임 이름 (그 영상이 실제로 그 게임 얘기일 때만) | 공식·제휴처럼 보이는 표현, 게임 깎아내리기 |
| | 사이트에 그 게임을 흉내 낸 게임 만들기 |
