# 홍보 이미지 디자인 (PROMO_DESIGN.md)

> 2026-11-20 BK "가자". 기준은 DIRECTION.md, 이 문서는 세부 규칙. 코드: `src/pipeline/promo_cards.py` + `scripts/promo_cards.js`.

## 1. 공통 틀
- 어두운 그라데이션 배경 + **두 줄 큰 제목**(한 줄 10자 이내) + 한 단어만 *기울임·색 강조*(`*끝.*`처럼 별표로 표시).
- 실제 화면(게임 플레이·계산 결과)을 **폰 목업** 안에 넣는다. 지어낸 화면 금지.
- 글꼴 주아. 원본 참고 이미지(r/ClaudeDesign 앱 홍보)의 그림·문구는 복제하지 않고 스타일만 따른다.
- 판매·특가·제휴·할인·쇼핑몰 이름·광고 문구 금지(코드가 `check()` 로 막음). 숫자는 사이트 데이터·계산기 공식으로만.

## 2. 세 가지 형식
| 형식 | 크기 | 쓰는 곳 | 만드는 법 |
|---|---|---|---|
| 5락실 세로 썸네일 | 1080x1920 | 5락실 쇼츠 썸네일·첫 장면, 인스타 스토리 | `python -m pipeline.promo_cards raksil <slug…> --out OUT` (게임마다 1장) |
| 5락실 가로 포스터 | 1280x720 | 레딧·커뮤니티 홍보, 공유 이미지 | 같은 명령에 게임 3개 이상이면 함께 나옴 |
| 돈삼촌 계산기 카드 | 1080x1350 | 인스타 카드뉴스(BK 수동 게시), 쇼츠 첫 장면 | `python -m pipeline.promo_cards calc --name 전기난로 --watts 1000 --hours 4 --out OUT` |

- 게임 폰 화면은 `scripts/game_posters.js` 를 `POSTER_PHONE=1` 로 돌려 390x844(2배) 세로로 찍는다(meta.json `poster` 조리법 재사용).
- 가로 포스터 카드 제목은 meta.json `"promo": {"t1": "봉투에", "em": "꽉"}`. 없으면 게임 이름 + "한 판".
- 계산기 카드는 지금 전기요금(가전 추가) 계산만. 식은 `calcs.COMMON_JS` 의 `bill()` 과 같고 테스트가 JS 와 비교한다.

## 3. 자동으로 만드는 것 (BK 11/20 "향후 새 콘텐츠는 자동, 이전 것은 안 만듦")
- **5락실 새 게임**: main 에 게임이 들어오면 Actions `posters` 가 포스터를 찍은 뒤 `python -m pipeline.promo_cards new` 로 세로 썸네일 1장을 `media/promo/raksil/<slug>.jpg` 에 만들어 커밋한다.
  - 대상: meta.json `added` 가 `PROMO_FROM`(2026-11-20) 이후이고 썸네일이 아직 없는 게임. 옛 게임은 만들지 않는다.
  - 실패해도 포스터 커밋은 그대로 진행(continue-on-error).
- **드라이브**: `drive-backup`(매일 03:30)이 `media/promo/` 를 드라이브 "자동 백업 (돈삼촌·5락실)/홍보이미지/<YYYY-MM>/" 로 올린다. BK는 거기서 받아 쇼츠·인스타에 쓴다.
- **계산기 카드**: 새 가전·계산기 콘텐츠를 만들 때 Claude 가 `calc` 명령으로 만든다(자동 예약 없음).

## 4. 아직 안 바꾸는 것
- 사이트 안 게임 포스터(`static/img/<slug>-poster.jpg`)와 사이트 레이아웃은 애드센스 심사 중이라 그대로 둔다. 승인 뒤 BK 확인 받고 적용 검토.
