# 만화 쇼츠 아이디어 은행 + 썸네일·훅 가이드 (SHORTS_BANK.md)

2026-11-13 BK 요청: 아이디어 30개를 모아 두고 무작위로 섞어 쓴다. 썸네일 문구·훅이 중요하다.
데이터: config/shorts_bank.json. 매일 대본 작업이 상황극 날(월·목·토)에 최근 15편에 안 쓴 아이디어 중 하나를 무작위로 받는다 (`episodes next` 의 concept).

## 1. 썸네일 = 첫 장면 (쇼츠는 첫 프레임이 피드·채널 목록에 보임)
- 구성: 위 자막 2줄(상황) + 가운데 노란 배지(질문·숫자) + 두 캐릭터의 과장된 표정. 글자는 배지 포함 12자 안팎.
- 배지 문구 공식 5가지
  1. 숫자 + 물음표: "1년 얼마?", "진짜 21만 원?"
  2. 상식 뒤집기: "끄면 손해라고?", "할인인데 손해?"
  3. 범인 찾기: "범인은 누구?", "꺼도 돈 먹는 1위"
  4. 금지·경고(정직하게): "이건 사지 마", "결제 전 3초"
  5. 비교 대결: "커피 vs 머신", "난방비 토너먼트"
- 금지: 내용에 없는 숫자, "무조건·100%·최저가 보장", 남의 캐릭터·로고·유명인 얼굴, 공포 조장.
- 상품 편도 썸네일엔 상품보다 질문이 먼저. 화면 위 막대 "광고 · 알리익스프레스 제휴 링크"는 처음부터 끝까지.

## 2. 훅 (0~2초)
- 결과부터: 굳은 삼촌, 고지서, 택배 산더미처럼 "왜 이렇게 됐지?"가 생기는 장면.
- 첫 대사는 조카의 구체적 행동 또는 숫자 ("새벽 두 시에 이거 결제했어!"). 인사·채널 소개 금지.
- 소리: 첫 프레임에 효과음(띵·쿵) 하나.

## 3. 다시 보게 (조회율 100%+)
- 반전 2번: 조카 오답 "땡!" → 삼촌도 빠뜨린 비용.
- 루프 엔딩: 마지막 대사·소리가 첫 장면으로 이어짐.
- 숨은 디테일: 배경에 다음 편 힌트(상자·고지서 숫자), 지난 편 소품 재등장.
- 2초마다 컷(확대·흔들림·배경 전환), 대사 1줄 = 정보 1개, 20~30초.

## 4. 원칙
- 원본 캐릭터(삼촌·조카)와 원본 대본만. 유행 밈·노래·다른 채널 대본 금지. 효과음은 직접 만든 것.
- 숫자는 상품 데이터·공식 자료로 다시 계산, 가정은 자막 sub·설명란.
- 상품 편: 제목 [광고], 설명란 첫 줄 고지, 유료 프로모션 체크. AI로 만든 인물이 나오면 AI 표기.
