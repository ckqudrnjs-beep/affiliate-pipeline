## 0. 문장 다듬기 규칙 (2026-11-26 BK "문장을 다듬어야 될 것 같아 적용할 규칙을 정리해서 반영해줘")
삼촌·5락실 쇼츠의 제목·화면 띠·자막(대사)·설명란 모두에 적용. 계기: 11/26 삼촌 기름 편 제목 "기름은 언제 넣느냐, 어디서 넣느냐? 뭐가 더 클까?"(옛말투 + 무엇이 큰지 없음), 띠 "어디서가 더 클까?", 자막 "길을 안다고 믿는 건 늘 자신감부터다"(주제와 따로 노는 격언). 11/25 "향후에 문장을 완벽하게"(5락실 미용실 편)와 같은 방향.
1. **처음 보는 사람 기준**: 앞 장면을 안 봐도 그 한 줄만 읽고 뜻이 통한다. 누가·무엇을이 빠진 문장 금지. (5락실은 흰 줄 = 무슨 일이 생겼는지, 11/25)
2. **요즘 말**: 소리 내어 읽어 자연스럽게. '~느냐·~는가·~로다·~노라·~이니라' 옛말투, '~에 있어서·~하는 것이 가능' 번역투 금지.
3. **비교 질문엔 기준**: 'A vs B, [기준]은 어느 쪽이 더 ~?'. 기준 = 전기요금·기름값·가스비·시간 등(금액 숫자는 계속 금지). '뭐가 더 클까?'·'어디서가 더 클까?' 금지.
   - 좋음: "기름값 차이, 넣는 날이 더 클까 주유소가 더 클까?", "가열식 vs 초음파 가습기, 한 달 전기요금 몇 배 차이?"
   - 나쁨: "기름은 언제 넣느냐, 어디서 넣느냐? 뭐가 더 클까?", "가습기 끓이는 것 vs 쪼개는 것"
4. **A·B는 같은 꼴, 아는 말로**: 명사 vs 명사, '~하기 vs ~하기'. 전문 용어를 풀다 생긴 엉뚱한 말·줄임말 금지(5락실 'X vs Y' 줄임말 띠는 제목에 안 씀, 11/26 PR #418).
5. **띠 질문 = 제목 질문 = 정답**: 셋이 같은 것을 묻고 답한다.
6. **자막은 주제와 이어지게**: 동전이 장면을 따라가되 이 편 질문과 연결. '~는 늘 ~부터다·~하는 법이다·~기 마련이다' 격언투 금지.
7. **한 문장 한 뜻**: 같은 말·어미 되풀이 금지(대비용 'A vs B'는 괜찮음).
8. **설명란 첫 줄 = 이 편 질문 한 문장**. 맞춤법·띄어쓰기는 `ko_check`(Kiwi)가 자동으로 고침(11/25).

적용: 규칙 글 `pipeline.copy_rules.SENTENCE_RULE` → 삼촌 대본 작가·다듬기·편집장 프롬프트(`claude_jobs.BAND_RULE`), 편집장 clarity 는 하나라도 어기면 5점 이하. 코드 점검 `copy_rules.copy_issues`(2·3·6번, 옛말투·기준 없는 비교·격언투): 대본 후보는 걸린 줄마다 4점 감점 + 다듬기 메모로 고치게, 11/28 공개분부터 대본 점검(`episodes.title_errors`)이 제목·띠를 막음. 이미 올린 영상은 제목만 수동 작업 `raksil-retitle`(채널 5락실/삼촌)로 고침, 영상은 지우지 않음.

## 1. 썸네일 = 첫 장면 (쇼츠는 첫 프레임이 피드·채널 목록에 보임)
- 구성: 위 자막 2줄(상황) + 가운데 노란 배지(질문·숫자) + 두 캐릭터의 과장된 표정. 글자는 배지 포함 12자 안팎.
- 배지 문구 공식 5가지
  1. 숫자 + 물음표: "1년 얼마?", "진짜 21만 원?"
  2. 상식 뒤집기: "끄면 손해라고?", "할인인데 손해?"
  3. 범인 찾기: "범인은 누구?", "꺼도 돈 먹는 1위"
  4. 금지·경고(정직하게): "이건 사지 마", "결제 전 3초"
  5. 비교 대결: "커피 vs 머신", "난방비 토너먼트"
- 금지: 내용에 없는 숫자, "무조건·100%·최저가 보장", 남의 캐릭터·로고·유명인 얼굴, 공포 조장.
- 상품 편도 썸네일엔 상품보다 질문이 먼저. 화면 위 막대 "광고 · 알리익스프레스 제휴 링크"는 처음부터 끝까지.

### 1-1. 동전이 편 제목 띠 + 유튜브 제목 (2026-11-20 BK "섬네일과 코멘트가 우선 사람들이 누르게, 필히 퀄리티 있는 문구로")
참고: BK가 YouTube Studio '조사'에서 본 살림 분야 실적 우수 쇼츠 — "의외로 모르는 대형마트 진실 3가지"(350만), "앞으로 삼겹살은 이렇게 드세요"(232만), "설거지가 끝나면 이걸 씁니다"(54만). 공통점 = 위쪽 굵은 두 줄 제목 띠 + 숫자·궁금증 훅 + 실제 생활 장면. 남의 문구는 쓰지 않고 형식만.
- 모양: 화면 맨 위 검은 띠(높이 360px), 위 줄 흰색·아래 줄 노란색, 주아. 첫 컷부터 마지막 컷까지 깔림(피드 썸네일이 곧 이 띠), 엔딩 클립엔 없음. 코드 `tools/toon_assemble.py` spec `"band": {"top", "accent"}`.
- 흰 줄(top, 14자 이하, 12자 권장): 누구나 겪는 생활 장면. 예) "추운 날 김치찌개 배달", "밥솥 보온 켜 둔 집".
- 노란 줄(accent, 14자 이하): 궁금증 한 줄 — 목록("의외로 모르는 3가지"), 지시("이것만 보세요"), 질문("동전이는 왜 저기 앉았을까?"), 상식 뒤집기("끄면 더 춥다고?"), 순위("겨울 집 TOP1"). **11/20 밤부터 돈·금액·'얼마 차이' 훅 금지**(돈 강조 금지, docs/DIRECTION.md 2-3).
- 답 금액(원)은 띠·제목에 넣지 않는다(숫자 상자에서 반전으로 한 번). 쇼핑몰·브랜드 이름, 무조건·100%·충격 같은 낚시 금지. `episodes.check` 가 글자 수·답 숫자·쇼핑몰 이름을 막고, 12/4 편부터 동전이 편은 띠 필수.
- 유튜브 제목(40자 이하): 띠와 같은 질문을 처음 보는 사람도 알게 풀어서, 답 없이 '?'로 끝. 비교 편은 기준(전기요금·기름값)을 넣는다(0장 3번, 11/26).
- **11/21 BK 결정(유튜브 분석 제목 패턴 3가지)**: ③ 지시어로 숨기기 채택 — 노란 줄 공식에 추가("동전이가 이걸 물고 왔다", "이거 그냥 담요가 아니다", 답은 화면에서). ① 구체 숫자는 시간·개수만("3초", "첫 1분", "세 번째"), 돈 액수·배수·%는 계속 금지. ② 손실 회피·금기 경고("~하지 마세요", "날릴 뻔", "모르면 손해")는 불채택 — 정보형·과장이라 금지, 채점 click 2점 이하.
- 공감 한 줄(세 편에 한 번, `claude_jobs.heart_turn`): 4번 컷 자막을 살림하는 사람 마음을 건드리는 한 줄로(20자 이하, 훈계·명언 인용 금지). 예) "아낀 건 돈이 아니라 내 저녁 한 시간".
- BK 11/20 김치찌개 시안 3종 중 **B 질문형**("추운 날 김치찌개 배달 / 집밥이랑 얼마 차이?") 선택 → 노란 줄은 질문형을 먼저 고려, 다른 공식은 편마다 섞는다. (질문형은 유지, 단 같은 날 밤 돈 강조 금지로 금액 질문은 안 씀)
- 07:10 `toon` 이 후보마다 띠·제목·공감 한 줄을 쓰고 채점에 click(누르고 싶은가) 10점을 더해 60점 만점으로 고른다. 상위 2안은 57점·클릭 9점이 될 때까지 최대 3번 다듬는다(BK "만점으로 기획하면 안되나?"; 채점은 깐깐하게 유지). 2시간 반응 규칙(`yt-early`)도 이 채점에 들어간다.

## 2. 훅 (0~2초)
- 결과부터: 굳은 삼촌, 고지서, 택배 산더미처럼 "왜 이렇게 됐지?"가 생기는 장면.
- 첫 대사는 조카의 구체적 행동 또는 숫자 ("새벽 두 시에 이거 결제했어!"). 인사·채널 소개 금지.
- 소리: 첫 프레임에 효과음(띵·쿵) 하나.

## 3. 다시 보게 (조회율 100%+)
- 반전 2번: 조카 오답 "땡!" → 삼촌도 빠뜨린 비용.
- 루프 엔딩: 마지막 대사·소리가 첫 장면으로 이어짐.
- 숨은 디테일: 배경에 다음 편 힌트(상자·고지서 숫자), 지난 편 소품 재등장.
- 2초마다 컷(확대·흔들림·배경 전환), 대사 1줄 = 정보 1개, 20~30초.

## 4. 원칙
- 원본 캐릭터(삼촌·조카)와 원본 대본만. 유행 밈·노래·다른 채널 대본 금지. 효과음은 직접 만든 것.
- 숫자는 상품 데이터·공식 자료로 다시 계산, 가정은 자막 sub·설명란.
- 상품 편: 제목 [광고], 설명란 첫 줄 고지, 유료 프로모션 체크. AI로 만든 인물이 나오면 AI 표기.
