# 삼촌의 글 자동 작성 (하루 1편, 승인 없이 바로 반영)

BK 결정 2026-11-10: 하루 1편을 사람 승인 없이 main에 바로 올린다. 대신 아래 규칙과 자동 검사(tests: ArticleDataTest)를 통과해야만 올린다.

## 순서 (예약 작업이 매일 그대로 따른다)
1. `data/article_topics.json`에서 `done:false`인 첫 질문을 고른다(형식은 `format`). 다 썼으면 기존 글·상품·계산기를 보고 검색 수요가 있는 새 질문을 하나 만든다(기존 글과 겹치지 않게).
2. `data/articles/<slug>.json` 작성. 필드: slug(영문 소문자-하이픈), date(오늘 KST), title, desc(160자 안팎, 답이 들어간 한 문장), keywords, body, products(0~2개, data/products의 slug), status "published".
3. `data/article_topics.json`의 해당 항목을 `done:true`, `slug` 추가.
4. `PYTHONPATH=src python -m unittest discover -s tests` 통과 + `PYTHONPATH=src python -m pipeline.site /tmp/site` 성공 확인 후 main에 커밋·푸시. 실패하면 고쳐서 다시, 그래도 안 되면 올리지 않는다.


## 사람이 쓴 것처럼 (BK 2026-11-10)
글마다 `data/article_topics.json`의 `format`을 따른다. 같은 형식이 이틀 연속 나오지 않게 한다.

| 형식 | 이렇게 쓴다 |
|---|---|
| 정보 | 검색 질문에 첫 문단에서 바로 답하고 계산·표로 뒷받침 |
| 비교 | 두세 가지를 같은 기준(돈·시간·수고)으로 나란히, 상황별로 "이럴 땐 이것" |
| 체크리스트 | 짧은 도입 + 체크 목록, 항목마다 왜 필요한지 한 줄 |
| 일기 | "삼촌의 일기" 말투. 오늘 든 생각·장면에서 시작해 계산·팁으로 이어짐 |
| 여행 | 여행·나들이 준비 메모. 일정·짐·전기·안전을 실제로 챙기듯 정리 |
| 질문 답장 | 독자가 물을 법한 질문 한 줄로 시작, 삼촌이 답장하듯 |

**말투:** 돈 줍는 삼촌. 친근한 ~해요체, 가끔 혼잣말(그렇더라고요, 저도 처음엔 몰랐어요). 문단 길이를 섞고, 숫자는 꼭 필요할 때만. "결론적으로", "다양한", "~하는 것이 중요합니다", "알아보겠습니다", "도움이 되셨길" 같은 기계적 표현과 매번 같은 틀(서론-본론-결론)은 피한다. 소제목도 질문형·말하듯 다양하게.

**지어내지 않기 (공정위·표시광고법):** 삼촌이 특정 상품을 직접 사서 써 봤다, 실제로 어디를 다녀왔다처럼 사실이 아닌 체험을 쓰지 않는다(가짜 후기에 해당). 일기·여행 글은 생각·계획·준비·계산·일반적인 상황("이럴 때 이렇더라고요"는 널리 알려진 내용만)으로 쓰고, 상품은 "이런 걸 고를 땐 ○○를 보세요" 수준으로 소개한다. 사용 후기·별점·효과 체감 표현 금지. 독자 질문은 "이런 질문을 자주 받아요"처럼 특정인 실화로 꾸미지 않는다.

## 글 규칙
- 주제는 블로그처럼 다양하게: 살림·난방·전기요금·직구·자동차·캠핑·IT·정리 등. 목적은 검색 유입 + 글 안에서 자연스러운 상품 소개. 같은 분야가 3일 연속 이어지지 않게 섞는다.
- 상품 소개: 본문에서 관련 상품을 사이트 상품 페이지 링크(`[이름](p/<slug>.html)`)로 1~3번 자연스럽게 언급할 수 있다(상품 페이지에 [광고] 표기와 계산이 있음). 글 끝 카드는 products 0~2개.
- 검색 질문에 바로 답한다. 첫 소제목에 결론(숫자)을 쓴다. 본문의 80% 이상은 답·계산·비교표.
- 숫자는 근거가 있어야 한다: 전기요금은 사이트 계산기와 같은 기준(src/pipeline/calcs.py의 bill(): 200/400kWh 누진, 120.0/214.6/307.3원, 기본 910/1,600/7,300원, 기후 9원·연료 5원/kWh, 부가세 10%, 기금 2.7%)으로 직접 계산한다. 관세는 목록통관 150달러(미국 200달러), 관세 8%·부가세 10% 기본. 모르는 수치는 지어내지 말고 "제품마다 다름, ○○에서 확인"으로 쓴다.
- 본문 형식: `## 소제목`(2개 이상), `- 목록`, `| 표 |`, `**굵게**`, `[글자](calc/electric.html)` 같은 사이트 안 링크만. 외부 링크·제휴 링크는 본문에 넣지 않는다.
- 본문 600자 이상, 보통 1,200~2,000자. 한국어, 친근한 존댓말(~해요), 과장 금지(articles.BANNED).
- 상품은 글 내용과 직접 관련 있을 때만 0~2개. 상품 카드는 글 끝에 [광고] 문구와 함께 자동으로 붙는다. 본문에서 "사세요" 식 권유 금지.
- 의약품·식품·화장품·건강 효능 주장 금지.
