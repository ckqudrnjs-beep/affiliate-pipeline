# 인스타그램·스레드 프로필 문구 (돈 줍는 삼촌)

원칙: 파는 계정이 아니라 생활비를 아껴 주는 정보 계정으로 보이게 쓴다. "최저가!!", "지금 구매", 이모지 도배는 쓰지 않는다. 제휴 사실은 프로필에 짧게 밝히고, 게시물마다 공정위 대가성 문구를 따로 단다 (COMPLIANCE.md).

## 인스타그램

이름 칸(검색에 걸림)과 소개(150자 이내)를 한 세트로 쓴다.

### 안 A: 신뢰형 (추천)
- 이름: `돈 줍는 삼촌 | 생활꿀팁·가성비템`
- 소개:
  ```
  직접 비교해 보고 괜찮은 것만 골라요
  주방·살림 꿀팁 / 소형가전 / 시즌 특가 정리
  일부 링크는 제휴 링크라 수수료를 받을 수 있어요
  ```

### 안 B: 친근형
- 이름: `돈 줍는 삼촌 · 살림 꿀팁`
- 소개:
  ```
  새는 생활비 같이 막아요 🙂
  아끼는 팁 위주, 진짜 쓸 만한 특가만 가끔
  광고·제휴 게시물은 항상 표시합니다
  ```

### 안 C: 담백형
- 이름: `돈 줍는 삼촌 | 생활비 아끼는 법`
- 소개:
  ```
  생활비 아끼는 팁과 가성비템을 정리합니다
  과장 없이 장단점까지
  제휴 링크가 있는 글은 [광고]로 표시
  ```

### 프로필 링크
- 쿠팡 상품 링크를 바로 걸지 않는다. 블로그 메인이나 "삼촌의 꿀팁 모음" 같은 정리 페이지 하나를 건다.
- 링크 제목 예: `생활꿀팁 모음`, `이번 주 특가 정리`
- 하이라이트 예: 주방 / 청소 / 소형가전 / 특가 / 알고보니

## 스레드 (150자 이내, 대화체)

- 안 A (추천): `생활비 아끼는 얘기 하는 삼촌입니다. 주방·살림 꿀팁이랑 써 볼 만한 특가를 나눠요. 제휴 링크가 있으면 꼭 밝힙니다.`
- 안 B: `오늘도 돈 줍는 중. 아끼는 팁이 먼저, 괜찮은 특가는 가끔. (제휴 링크엔 광고 표시)`
- 안 C: `살림·소형가전 정보를 정리합니다. 살 때 가격 말고 1년 총비용으로 비교해 드려요. 일부 링크는 제휴 링크예요.`
