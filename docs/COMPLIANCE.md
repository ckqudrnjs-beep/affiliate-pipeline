# 법·정책 준수 체크리스트 (COMPLIANCE.md)

> 최종 갱신: 2026-11-07 · 모든 에이전트는 발행 전에 이 문서를 검사 규칙으로 사용합니다.

## 1. 공정위 추천·보증 심사지침 (경제적 이해관계 표시)
- 2024-12 개정 지침: 표시는 **제목 또는 게시물 첫 부분**에. "더보기"를 눌러야 보이는 위치는 부족.
- 2025-12-02 공정위가 안내서(Q&A 25개) 개정본 배포. 4대 원칙: 접근성·인식가능성·명확성·언어 동일성.
- 모호한 표현("수수료를 받을 수 있음") 대신 명확한 표현("수수료를 제공받습니다").
- 프로필에만 표시하고 게시물엔 없는 방식은 부족.
- 영상: 시작 부분 + 설명란 첫 줄, 쇼츠는 화면 자막으로도.

### 표준 문구 (템플릿)
- 쿠팡: `이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.`
- 네이버: `이 포스팅은 네이버 쇼핑 커넥트(브랜드 커넥트) 활동의 일환으로, 판매 발생 시 일정액의 수수료를 제공받습니다.`
- 공통: `[광고] 이 글에는 제휴 링크가 포함되어 있으며, 구매 시 작성자가 일정액의 수수료를 제공받습니다.`
- 한 글에 여러 프로그램 링크가 있으면 프로그램명을 모두 표기.

> 쿠팡 문구는 각 사 공식 가이드로 최종 확인 필요(현재 근거는 비공식 블로그).

## 2. 자동 검사 규칙 (발행 차단 조건)
- [ ] 첫 200자(또는 제목) 안에 대가성 문구 없음 → 차단
- [ ] 제휴 링크가 공식 도메인/공식 API 생성 링크가 아님 → 차단
- [ ] 가격·스펙에 출처/수집 시각 없음 → 차단
- [ ] "직접 써봤다" 등 체험 표현이 있는데 실사용 근거 없음 → 차단
- [ ] 의료·금융 효능 주장 → 차단 (건강기능식품·의료기기 광고 규제)
- [ ] 같은 계정 24시간 발행량 한도 초과 → 대기 (스레드 3, 인스타 2. `publish.py`)
- [ ] 같은 문구를 같은 채널에 다시 게시 → 차단 (반복 게시 방지)
- [ ] 발행 직전 위 검사를 채널별 최종 본문(인스타는 링크 치환 후 캡션)으로 다시 실행

## 3. 플랫폼 약관 요약
- 공식 API만 사용. 브라우저 매크로·비공식 자동화·다계정 운영 금지.
- 유튜브: 반복·템플릿형 콘텐츠 수익화 제외, AI 합성 사실적 콘텐츠는 표시.
- 쿠팡 파트너스: 위반 시 수익 몰수·계정 정지 가능. 금지 행위는 가입 후 운영정책 원문으로 확인해 이 문서에 추가.

## 4. 세금 (사용자 결정 필요)
- 제휴 수익은 일반적으로 사업소득/기타소득으로 원천징수(3.3% 등) 후 지급되는 경우가 많음 (*프로그램별 확인 필요*).
- 반복·계속적 수익이면 사업자등록(전자상거래/정보통신 관련 업종) 검토. 연 매출 규모에 따라 간이/일반 과세.
- 본업 회사의 겸업 금지 규정 확인.
- 정확한 판단은 세무사 상담 권장.

## 5. Meta(스레드·인스타) 정책 요약
- 공식 API(Threads API, Instagram API)로 본인 계정에만 게시. 다계정·매크로 금지.
- 대가성 문구는 캡션 첫 줄(더보기 전에 보이도록). 프로필 표기만으로는 부족.
- 사실적 AI 생성 이미지·영상은 AI 라벨 표시. 이미지는 사용 권리가 있는 것만.
