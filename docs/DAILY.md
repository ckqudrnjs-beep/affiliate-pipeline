## A. 오늘의 생활 시세 (홈 맨 위)
- `.github/workflows/daily.yml` 매일 05:50 KST → `src/pipeline/daily.py` → `data/daily/YYYY-MM-DD.json` main 커밋 → 사이트 재빌드.
- 휘발유·경유 전국 평균(어제 대비), 우리 지역(시도 선택, 이 기기에 기억), 1달러 환율, 장바구니(KAMIS 키가 생기면 자동 표시).
- 판단 문장은 숫자 규칙만(기름값 7일 추이, 환율 4주 평균 대비, 장바구니 한 달 변화). 출처 표시.
- 키는 주간 리포트와 같음: OPINET_KEY, ECOS_KEY, KAMIS_KEY+KAMIS_ID. 없는 출처는 칸이 빠지고, 다 없으면 퀴즈만 보인다.

## B. 오늘의 얼마게 (홈 + /quiz)
- 하루 1문제, 4지선다. 문제는 사이트 계산값으로만: 레시피 1인분 재료비·배달 대비 절약(30), 가전 전기요금(10), 대기전력(1), 직구 면세 한도(1) + 3일에 한 번 그날 휘발유/환율. 같은 날짜는 언제 빌드해도 같은 문제(30일 안에 겹침 없음). 문제를 늘리려면 레시피·질문 페이지를 늘리면 자동으로 늘어난다.
- 출석 도장(풀면 찍힘, 틀려도 찍힘), 연속 일수, 최근 7일 도장, 배지 3·7·14·30·100일, '내일 휘발유 오를까' 예측 → 다음 날 적중 표시, 결과 공유(링크 포함).
- 기록은 localStorage `d3c_daily`, 지역은 `d3c_region`. 서버 저장·개인정보 없음. 보상은 배지뿐(돈·광고와 무관).
