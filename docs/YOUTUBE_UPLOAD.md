# 유튜브 쇼츠 올리기 (BK가 직접, 휴대폰 또는 YouTube Studio)

> 2026-11-09 · 판매자 제공 사진(알리 공식 API)으로 만든 쇼츠 6개. **2~3일에 1개씩** 올린다 (혹시 저작권 신고가 와도 1건에서 멈추게).
> 파일: `video/youtube/<상품>.mp4` (질문 → 상품 → 계산 카드 → 가격·don3chon.com, AI 내레이션 7번 목소리)

## 올릴 때마다 할 것 (공통)
1. 제목 맨 앞에 **[광고]**
2. 세부정보 → **유료 프로모션 → "동영상에 간접 광고, 스폰서십 등 유료 프로모션이 포함되어 있음" 체크**
3. 설명 **첫 줄**에 광고 문구 (아래 그대로), 링크는 그 아래
4. 시청자층: "아동용 아님"
5. "변경되거나 합성된 콘텐츠"는 체크하지 않아도 됨 (실제 상품 사진 편집 + 일반 AI 내레이션). 설명 끝에 "내레이션: AI 음성" 한 줄

쇼츠 설명란 링크는 눌리지 않아요. 그래서 영상 끝 화면과 설명에 **don3chon.com**을 적어 사이트로 오게 해요. 사이트 상품 카드에 제휴 링크가 있어요.
