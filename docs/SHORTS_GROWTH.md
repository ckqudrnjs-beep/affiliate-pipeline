## 2026-11-18 실사 배경 상황극 (BK "실사 영상이 좋아, 기획안 돌려 쓰면 지겨울 것")
- **모양**: 주제에 맞는 실제 영상(한파 → 눈 내린 길, 난방비 → 보일러, 장보기 → 시장 채소) 배경 + 우리 숫자·큰 자막 + 아래 왼쪽 말하는 사람 작은 동그라미(삼촌/조카 그림) + 아래 오른쪽 작은 동전이. 반전 숫자 줄은 배경을 선명하게 둔 채 살짝 어둡게만 하고 숫자만 크게(흐리게 금지, BK 11/19). 코드 `src/pipeline/live.py`, 대본 맨 위 `"style": "live"`, 첫 줄 `clip`(장면 사전 이름, 없는 줄은 앞 장면 이어씀)·`src`(출처)·`layout`(full/focus).
- **영상 출처 (저작권)**: 상업 이용 무료 스톡만 — Pexels API(`PEXELS_API_KEY`) → 없으면 Pixabay API(`PIXABAY_API_KEY`). 남의 유튜브·뉴스·연예인 인터뷰·방송 화면은 쓰지 않는다(저작권·재사용 콘텐츠·초상권). 공공누리 영상은 출처 표시 조건을 확인한 것만, 사람이 골라 넣을 때만.
- **공개 저장소 주의**: 스톡 원본 파일은 저장소에 올리지 않는다(렌더할 때 받아 쓰고 버림). 쓴 영상 id 만 `data/stock_used.json` → 30일 안에 같은 영상 재사용 금지(반복 콘텐츠 방지). 촬영자·페이지는 meta.json `credits` → 설명란 "배경 영상(무료 스톡): …" 자동, 화면 아래에도 작게.
- **요일**: ~~월·화·토 = 실사, 목·금 = 웹툰, 수·일 = 카드~~ → 2026-11-19 BK "스토리와 첨단 도구": **매일 실사·AI 배경 + 스토리(착각→반전 숫자→두 번째 숫자→할 일) skit**, 글자 카드만 있는 편 없음. `episodes.LIVE_DAYS`·`STORY_RULE`. 키가 없거나 받기 실패하면 그날은 자동으로 웹툰 (빠지는 날 없음).
- **시기 이슈**: 그 주의 한파·김장·요금 인상·명절을 주제로 잡되 금액·%는 사이트 숫자만. 기온·인상 시점 같은 바깥 사실은 줄 `src`(예 "기상청 11/18 중기예보")로 출처를 달고, 확인 안 된 것·겁주기 과장은 쓰지 않는다. 예: 한파 주간 → /calc/heating "1도 낮추면 한 달 약 1만 400원".
- **그대로 지키는 것**: 주부 타깃, 아하 1개, 첫 1초 badge, 상품·제휴 없음, 끝 구독 한 줄, AI 표기(화면 "AI 음성 · AI로 그린 가상 캐릭터" + 설명란).
- **판단 (12/7, 2주)**: 실사 편(월·화·토) vs 웹툰 상황극(목·금)의 평균 시청 비율·조회수. 실사가 둘 다 높으면 목·금도 실사로, 둘 다 낮으면 실사는 화요일(시기 이슈)만 남긴다.
- **비용**: 0원 (Pexels·Pixabay API 무료, 렌더는 GitHub Actions).
- **11/18 샘플 피드백 반영 (BK: "1도 차이는 티도 안 나지"에 지구본, "겨울 4달 8만 8천 원"에 흐린 산장)**: 원인은 ① 대사마다 자유 검색어로 새 영상을 찾고 ② 검색 1등을 그대로 썼기 때문. 바꾼 점: clip 은 장면 사전 `config/stock_scenes.json`(25개: snow-street, boiler, thermostat, grocery-market, cabbage …) 이름만 → 영상 태그에 그 물건 단어가 있어야 쓰고(need), 지구본·우주·산장·숲·드론·CG 같은 태그는 버림(ban_all) → 눈으로 확인한 영상(ok)을 먼저, 어색했던 영상(bad)은 다시 안 씀. 한 편에 장면 1~3개, 말·숫자 줄은 앞 장면을 이어서(배경 흐림). 렌더할 때 줄마다 화면을 모은 확인 그림 `media/youtube/<slug>.check.jpg` 를 같이 남겨, 어색한 장면의 영상 id 를 bad 에 넣는다.

### 원칙
- **형식은 3개만** (요일마다 형식이 바뀌면 기억되지 않음): ① 장바구니 시세 ② 살림 상황극 ③ "1년이면 얼마?" 카드.
- **보는 사람 = 장보기·살림 맡은 30~50대(주부)**. 주제: 장바구니·집밥·전기/가스/난방·김장·관리비. 조카는 시청자 대신 묻고, 펀치라인은 "엄마한테 전화할게" 같은 집안 장면.
- **아하 1개 필수**: 흔한 믿음을 사이트 숫자로 뒤집는다. 예) "밥솥 보온은 전기 거의 안 먹지?" → 한 달 약 7,420원, 1년 약 8만 9천 원. "김장철이라 무도 비싸겠지?" → 고랭지 무 한 달 -27%(11/16 KAMIS). 사이트에 근거 없는 아하는 금지.
- **마스코트 강아지 '동전이'**: 삼촌네 둥근 시바 강아지(코드로 그림, `src/pipeline/pet.py`, 비용 0). 상황극 화면 아래 가운데 고정, 줄마다 통 튀어 오르고, 반전 숫자 때 동전을 물고 "짤랑!"(효과음). 포즈 6개 happy/shock/coin/curious/cry/sleep, 대본 줄에 `pet`·`pet_say`(8자 이하)로 지정, 없으면 분위기로 자동. 실제 반려동물 영상이 아님.

## 쇼츠가 퍼지는 방식 (조사 요약)
- 새 쇼츠는 먼저 작은 시청자 묶음에 보여 주고, **"본 사람 vs 넘긴 사람" 비율**과 **평균 시청 비율(반복 포함)**이 좋으면 더 큰 묶음으로 넓힌다. 첫 1~2초에 넘기면 거기서 멈춘다.
