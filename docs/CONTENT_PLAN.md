# 돈 줍는 삼촌: 계정 목적과 콘텐츠 구성 (CONTENT_PLAN.md)

> 최종 갱신: 2026-11-07 · 인스타그램·스레드 공통. 운영 규칙은 OPERATIONS.md, 프로필 문구는 PROFILE_COPY.md.

## 1. 계정의 주요 목적

**한 줄 정의:** "새는 생활비를 막아 주는 삼촌." 사람들이 장보기·살림·가전 고르기 전에 한 번 들러서 확인하는 계정.

| 목적 | 팔로워가 얻는 것 | 계정이 얻는 것 |
|---|---|---|
| 1. 생활비 아끼는 정보 | 바로 써먹는 팁 (전기료, 세척, 보관, 고르는 법) | 저장·공유 → 도달 증가 |
| 2. 실패 없는 선택 도와주기 | 비교표, 체크리스트, 장단점 | 신뢰 → 추천을 믿게 됨 |
| 3. 진짜 괜찮은 특가 알려 주기 | 시기에 맞는 할인 정보 | 제휴 수수료 (표기 필수) |

순서가 중요하다. 1과 2로 신뢰를 쌓고, 3은 그 위에 가끔 얹는다. 정보형이 항상 홍보형보다 많다.

**하지 않는 것:** 써 보지 않은 제품의 사용 후기, "무조건 사세요", "역대급 최저가" 같은 과장, 광고 표시 없는 링크.

## 2. 콘텐츠 기둥 (고정 시리즈 5개)

| # | 시리즈 이름 | 내용 | 비율 | 형식 |
|---|---|---|---|---|
| 1 | **삼촌의 살림 꿀팁** | 세척·보관·정리·절약 요령 | 35% | 스레드 글, 인스타 캐러셀 5~7장 |
| 2 | **고르기 전에 체크** | 제품 고르는 기준, 스펙 읽는 법, 비교표 | 20% | 캐러셀, 스레드 긴 글 |
| 3 | **이번 달 준비할 것** | 시즌 체크리스트 (11월: 난방·건조·김장) | 10% | 캐러셀, 스레드 |
| 4 | **삼촌이 주운 특가** | 기준을 통과한 제품 1~3개 + 장단점 | 25% 이하 | 스레드 링크, 인스타 스토리 링크 |
| 5 | **물어보세요** | 질문·투표, 받은 질문 답변 | 10% | 스레드 질문, 인스타 스토리 투표 |

- 주제는 묶어서 낸다: 꿀팁(1) → 고르는 법(2) → 특가(4). 예: 전기요 안전하게 쓰기 → 전기요 고르는 기준 → 전기요 특가.
- 특가(4)에 올리는 제품 기준: 리뷰 수 충분, 평점 4.5 이상, 최근 가격보다 실제로 쌈, 단점도 한 줄 이상 쓸 수 있음.

## 3. 주간 편성 (첫 2주는 하루 1~2개로 시작)

## 4. 인스타 하이라이트 (5개)

`📌 처음이세요` (소개 글) · `🧽 살림꿀팁` · `🔍 고르는법` · `🏷️ 특가` · `💬 질문답변`

커버는 단색 배경 + 흰 아이콘으로 통일한다.

## 5. 고정 게시물 (소개 글)

### 스레드 고정 글
```
안녕하세요, 돈 줍는 삼촌입니다.

여기서는 이런 걸 나눠요.
· 생활비 새는 곳 막는 살림 꿀팁
· 가전·생활용품 고르기 전에 볼 체크리스트
· 기준을 통과한 특가만 가끔

약속 세 가지.
1. 써 보지 않은 건 써 본 척하지 않아요
2. 장점만 말하지 않고 단점도 같이 적어요
3. 제휴 링크가 들어간 글은 첫 줄에 꼭 밝혀요

궁금한 제품이나 살림 고민 있으면 댓글로 물어보세요. 삼촌이 대신 찾아볼게요.
```

### 인스타 고정 캐러셀 (5장)
1. 표지: "돈 줍는 삼촌은 이런 계정이에요"
2. "생활비 새는 곳 막는 살림 꿀팁"
3. "사기 전에 볼 체크리스트와 비교표"
4. "기준 통과한 특가만, 광고 표시는 항상"
5. "궁금한 건 댓글·DM으로. 저장해 두고 필요할 때 꺼내 보세요"

캡션:
```
돈 줍는 삼촌 계정 소개예요.
살림 꿀팁, 고르는 기준, 괜찮은 특가를 정리합니다.
제휴 링크가 있는 게시물은 첫 줄에 [광고]로 표시해요.
#살림꿀팁 #생활비절약 #자취꿀팁
```

## 6. 첫 정보형 게시물 4개 (링크 없음, 대가성 문구 불필요)

> 자동 발행 대기열: 스레드 소개 글, ②, ③ 을 config/tips.csv 에 추가했다 (2026-11-07). ①·④ 는 같은 주제 글(전기요 안전, 난방비 절약)이 이미 풀에 있어 넣지 않았다. 고정(핀)은 API로 안 되므로 소개 글이 올라가면 앱에서 직접 고정한다. 인스타는 이미지가 있는 글만 자동 발행되므로 소개 캐러셀은 앱에서 직접 올린다.

### ① 삼촌의 살림 꿀팁: 전기요 안전하게 쓰기
```
전기요 꺼내기 전에 이것만 확인하세요.

1. 접힌 채로 보관했다면 꺾인 자국·탄 자국부터 확인
2. 위에 무거운 이불 여러 겹 덮지 않기 (열이 갇혀요)
3. 자기 전엔 고온 말고 저온 + 타이머
4. 전선이 매트리스 사이에 끼지 않게
5. 오래 써서 온도 조절이 이상하면 수리보다 교체

작은 습관이 화재를 막아요. 저장해 두고 이불 꺼낼 때 다시 보세요.
```

### ② 고르기 전에 체크: 가습기 방식 3가지
```
가습기 살 때 제일 먼저 볼 건 "방식"이에요.

· 초음파식: 저렴하고 조용함. 대신 물통 세척을 자주 해야 해요
· 가열식: 끓여서 내보내 위생적. 전기료가 더 들고 뜨거워요
· 자연기화식: 전기료 적고 과습이 덜해요. 가습량은 약한 편

아이 방이면 위생, 거실이면 가습량, 오래 틀면 전기료를 먼저 보세요.
여러분은 어떤 방식 쓰세요?
```

### ③ 이번 달 준비할 것: 11월 체크리스트
```
11월에 미리 해 두면 겨울이 편해요.

□ 보일러 시운전 (한 번 틀어서 소리·누수 확인)
□ 창문 틈 막기 (문풍지, 뽁뽁이)
□ 가습기 꺼내서 세척 후 사용
□ 전기요·온수매트 점검
□ 김장 일정 있으면 김치냉장고 비우기
□ 수도 계량기함 보온재 확인

몇 개 하셨어요?
```

### ④ 살림 꿀팁: 난방비 줄이는 습관
```
난방비, 보일러 끄는 것보다 이게 더 효과 있어요.

1. 외출할 때 끄지 말고 외출 모드로 (식었다 다시 데우는 게 더 들어요)
2. 바닥에 러그·카펫 깔기
3. 창문에 암막·두꺼운 커튼
4. 실내 18~20도 + 가습 (습도가 높으면 덜 춥게 느껴요)
5. 안 쓰는 방 밸브는 잠그기

집 구조마다 차이는 있어요. 우리 집에 맞는 걸 골라 써 보세요.
```

> 숫자·효과는 일반적인 안내 수준으로만 썼다. 구체적인 절감액을 넣을 땐 한국에너지공단·제조사 자료 등 출처를 확인하고 넣는다.
