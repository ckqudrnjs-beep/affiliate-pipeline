# 돈 줍는 삼촌: 계정 목적과 콘텐츠 구성 (CONTENT_PLAN.md)

> 최종 갱신: 2026-11-07 · 인스타그램·스레드 공통. 운영 규칙은 OPERATIONS.md, 프로필 문구는 PROFILE_COPY.md.

## 1. 계정의 주요 목적

**한 줄 정의:** "새는 생활비를 막아 주는 삼촌." 사람들이 장보기·살림·가전 고르기 전에 한 번 들러서 확인하는 계정.

| 목적 | 팔로워가 얻는 것 | 계정이 얻는 것 |
|---|---|---|
| 1. 생활비 아끼는 정보 | 바로 써먹는 팁 (전기료, 세척, 보관, 고르는 법) | 저장·공유 → 도달 증가 |
| 2. 실패 없는 선택 도와주기 | 비교표, 체크리스트, 장단점 | 신뢰 → 추천을 믿게 됨 |
| 3. 진짜 괜찮은 특가 알려 주기 | 시기에 맞는 할인 정보 | 제휴 수수료 (표기 필수) |

순서가 중요하다. 1과 2로 신뢰를 쌓고, 3은 그 위에 가끔 얹는다. 정보형이 항상 홍보형보다 많다.

**하지 않는 것:** 써 보지 않은 제품의 사용 후기, "무조건 사세요", "역대급 최저가" 같은 과장, 광고 표시 없는 링크.

## 2. 콘텐츠 기둥 (고정 시리즈 5개)

| # | 시리즈 이름 | 내용 | 비율 | 형식 |
|---|---|---|---|---|
| 1 | **삼촌의 살림 꿀팁** | 세척·보관·정리·절약 요령 | 35% | 스레드 글, 인스타 캐러셀 5~7장 |
| 2 | **고르기 전에 체크** | 제품 고르는 기준, 스펙 읽는 법, 비교표 | 20% | 캐러셀, 스레드 긴 글 |
| 3 | **이번 달 준비할 것** | 시즌 체크리스트 (11월: 난방·건조·김장) | 10% | 캐러셀, 스레드 |
| 4 | **삼촌이 주운 특가** | 기준을 통과한 제품 1~3개 + 장단점 | 25% 이하 | 스레드 링크, 인스타 스토리 링크 |
| 5 | **알고 보니** | 흔한 오해 바로잡기 ("외출 땐 보일러 끄기"가 오히려 손해인 경우 등). 매 글에 "아하" 포인트 하나 | 10% | 스레드, 인스타 스토리 퀴즈 스티커 |

- 주제는 묶어서 낸다: 꿀팁(1) → 고르는 법(2) → 특가(4). 예: 전기요 안전하게 쓰기 → 전기요 고르는 기준 → 전기요 특가.
- 특가(4)에 올리는 제품 기준: 리뷰 수 충분, 평점 4.5 이상, 최근 가격보다 실제로 쌈, 단점도 한 줄 이상 쓸 수 있음.

## 6. 첫 정보형 게시물 4개 (링크 없음, 대가성 문구 불필요)

> 자동 발행 대기열: 스레드 소개 글, ②, ③ 을 config/tips.csv 에 추가했다 (2026-11-07). ①·④ 는 같은 주제 글(전기요 안전, 난방비 절약)이 이미 풀에 있어 넣지 않았다. 고정(핀)은 API로 안 되므로 소개 글이 올라가면 앱에서 직접 고정한다. 인스타는 이미지가 있는 글만 자동 발행되므로 소개 캐러셀은 앱에서 직접 올린다.

### ① 삼촌의 살림 꿀팁: 전기요 안전하게 쓰기
```
전기요 꺼내기 전에 이것만 확인하세요.

1. 접힌 채로 보관했다면 꺾인 자국·탄 자국부터 확인
2. 위에 무거운 이불 여러 겹 덮지 않기 (열이 갇혀요)
3. 자기 전엔 고온 말고 저온 + 타이머
4. 전선이 매트리스 사이에 끼지 않게
5. 오래 써서 온도 조절이 이상하면 수리보다 교체

작은 습관이 화재를 막아요. 저장해 두고 이불 꺼낼 때 다시 보세요.
```

### ② 고르기 전에 체크: 가습기 방식 3가지
```
가습기 전기료, 방식 하나로 10배까지 차이 나요.

· 가열식: 약 300W → 하루 8시간 쓰면 한 달 약 72kWh
· 초음파식: 약 30W → 같은 조건이면 한 달 약 7kWh
· 자연기화식: 전기는 적게 들고 과습이 덜해요. 가습량은 약한 편

대신 초음파식은 물통을 자주 씻어야 하고, 가열식은 끓여서 내보내 위생적이에요.
위생이 1순위면 가열식, 오래 틀 거면 초음파식에 세척 습관을 더하세요.
(소비전력은 제품마다 달라요. 살 때 라벨의 W부터 보세요)

가습기 사려는 사람에게 보내 주세요.
```

### ③ 이번 달 준비할 것: 11월 체크리스트
```
보일러는 첫 한파가 오고 나서 점검하면 늦어요. AS 접수가 한꺼번에 몰리거든요.

11월에 미리 해 둘 것.
□ 보일러 시운전 (한 번 틀어서 소리·누수 확인)
□ 창문 틈 막기 (문풍지, 뽁뽁이)
□ 가습기 꺼내서 세척 후 사용
□ 전기요·온수매트 접힌 자국·전선 점검
□ 수도 계량기함 보온재 확인

저장해 두고 이번 주말에 하나씩 지워 보세요.
```

### ④ 살림 꿀팁: 난방비 줄이는 습관
```
난방비, 보일러 끄는 것보다 이게 더 효과 있어요.

1. 외출할 때 끄지 말고 외출 모드로 (식었다 다시 데우는 게 더 들어요)
2. 바닥에 러그·카펫 깔기
3. 창문에 암막·두꺼운 커튼
4. 실내 18~20도 + 가습 (습도가 높으면 덜 춥게 느껴요)
5. 안 쓰는 방 밸브는 잠그기

집 구조마다 차이는 있어요. 우리 집에 맞는 걸 골라 써 보세요.
```

## 7. 인스타그램 전용 콘셉트: "계산식을 공개하는 삼촌"

### 왜 이 콘셉트인가
인스타의 생활꿀팁·핫딜 계정은 대부분 "최저가!", "이거 사세요", 예쁜 제품 사진이다. 팔로워 0인 계정이 같은 걸 하면 묻힌다.
돈 줍는 삼촌은 **모든 걸 원 단위로 계산하고, 계산식을 그대로 보여 준다.** "이 습관 1년에 얼마 새는지", "이 제품 1년 총비용이 얼마인지".
- 숫자가 있으니 저장·공유가 잘 된다 ("우리 집 셋톱박스 13,140원이래")
- 계산식을 공개하니 광고 계정처럼 보이지 않는다. 특가 글도 "계산해 보니 이득"이라는 근거가 붙는다
- 제품 사진이 없어도 되는 텍스트·도표 중심이라 **이미지 자동 생성이 쉽다** (사진 저작권 문제도 없음)

### 시그니처 포맷 3개 (인스타 피드는 이 셋만 돌린다)

| 포맷 | 생김새 | 내용 | 비율 | 링크 |
|---|---|---|---|---|
| **삼촌 영수증** | 마트 영수증 모양 카드, 빨간 "새는 돈" 도장 | 습관·기기 하나가 1년에 쓰는 돈 계산 (대기전력, 구독료, 배달비, 생수 vs 정수기) | 40% | 없음 |
| **살까 말까 저울** | 좌우 두 칸 비교 + 아래 "삼촌 결론" 박스 | 두 선택지의 1년 총비용 (구매가 + 전기료 + 소모품) | 35% | 홍보형일 때만, 첫 줄·이미지에 광고 표기 |
| **이번 달 삼촌 체크카드** | 체크박스 한 장 카드, 저장 유도 | 시즌 준비 목록 (11월 난방·건조, 12월 연말정산 준비 등) | 25% | 없음 |

캐러셀 구조(5~7장): 1장 질문형 표지 → 2~4장 계산·비교 → 5장 삼촌 결론 → 마지막 장 "저장해 두고 장보기 전에 꺼내 보세요" + 다음 편 예고.

### 시각 템플릿 규칙
- 색: 크림(#f4efe6) 배경, 진남색(#1f2a2e) 글자, 빨강(#d6452f)은 "새는 돈", 초록(#2f7d5b)은 "아낀 돈". 이 네 색만 쓴다
- 글꼴: 제목 Noto Sans KR Black, 영수증 숫자는 고정폭 글꼴
- 모든 장 오른쪽 위에 "돈 줍는 삼촌", 계산 장 아래에 가정·출처 한 줄
- 예시: [영수증](insta/example-s1.png), [저울](insta/example-s2.png), 원본 HTML [template-example.html](insta/template-example.html)

### 캐릭터·말투
- 삼촌 = 숫자로 잔소리하는 다정한 사람. "삼촌이 계산해 봤는데", "이건 새는 돈이야", "이건 아껴도 되는 돈"
- 얼굴 캐릭터나 AI 인물 사진은 쓰지 않는다 (만들 시간·AI 표기 부담). 도장과 영수증이 캐릭터 역할을 한다

### 저장·공유를 부르는 장치
- 결론 장에 "내 기기는 몇 W?" 처럼 직접 확인해 볼 것 한 줄 → 확인하려고 저장
- 매달 1일 "이번 달 체크카드" 고정 발행 → 다시 찾아오는 이유
- 스토리 퀴즈 스티커 "이거 1년에 얼마일까? A 5천 원 / B 1만 3천 원" → 다음 날 영수증 공개 (댓글이 아니라 탭 한 번으로 참여)

### 자동화
- 글 데이터(제목, 계산 항목, 결론)를 CSV/JSON으로 두고, HTML 템플릿을 Playwright로 1080×1350 이미지로 렌더링한다 (예시 두 장도 이 방식으로 만듦). 비용 0원
- 인스타 API는 캐러셀(여러 장) 발행을 지원한다. 지금 publish.py 는 한 장만 올리므로 캐러셀 발행 기능 추가가 필요하다
- **걸림돌:** 인스타 API는 공개 이미지 URL만 받는다. 저장소가 비공개라 GitHub raw 주소는 못 쓴다. 이미지 전용 공개 저장소(GitHub Pages, 무료)나 무료 이미지 호스팅이 필요하다 (결정 필요)
- 처음 2주는 사용자가 이미지를 확인하고 승인한 뒤 발행한다

### 정책 준수
- 계산은 "예시·가정"임을 이미지와 캡션에 밝히고, 소비전력은 제품 라벨, 요금은 한전 요금표 등 출처를 단다. 과장된 절감액은 쓰지 않는다
- 홍보형 저울은 캡션 첫 줄 대가성 문구 + 이미지 왼쪽 위 "광고" 표기, 가격은 "○월 ○일 기준"
- 써 보지 않은 제품은 "후기"가 아니라 "스펙 비교"로만 쓴다

## 8. 반응 목표와 댓글 정책 (2026-11-07 결정)

- **댓글은 받지 않는다.** 인스타는 게시물마다 "댓글 기능 해제", 스레드는 답글 가능 대상을 "멘션한 프로필"로 제한한다 (앱 설정, 사용자가 직접). 운영 부담과 악플·스팸 대응을 없애기 위해서다.
- 그래서 글 끝 행동 유도(CTA)는 **저장 · 공유 · 팔로우** 세 가지만 쓴다. "댓글로 알려 주세요", "몇 개 하셨어요?" 같은 문구는 쓰지 않는다.
  - 저장: 체크리스트·계산표 글 ("저장해 두고 살 때 꺼내 보세요"). 다시 볼 이유가 있는 글이라는 신호
  - 공유: 비교·"알고 보니" 글 ("가습기 사려는 사람에게 보내 주세요"). 팔로워가 아닌 사람에게 도달하는 가장 큰 통로
  - 팔로우: 소개 글·시리즈 글 ("새 계산이 올라올 때 보려면 팔로우")
  - 좋아요는 따로 요청하지 않는다
- 참여는 스토리 퀴즈·투표 스티커처럼 탭 한 번으로 끝나는 장치로 대신한다.
- 모든 글 첫 문장은 "아하" 한 줄로 시작한다: 의외의 숫자나 흔한 오해 (예: "가습기 전기료, 방식 하나로 10배 차이").
