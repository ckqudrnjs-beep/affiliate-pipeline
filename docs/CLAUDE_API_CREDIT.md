# Claude API 크레딧 활용 계획 (매월 100달러)

작성 2026-11-19. BK가 Claude 플랫폼(console.anthropic.com)에서 API 크레딧 100달러를 받음. BK 말로는 **매달 나오는 것 같음** → 남겨도 이월 안 될 수 있으니 "매달 꾸준히 쓰는 곳" 위주로 잡는다.

## BK가 콘솔에서 직접 확인할 것 (5분)
1. **Billing → Credits**: 만료일, 매월 지급인지(지급 내역 날짜), 남은 금액.
2. **Limits → Spend limit**: 월 한도를 **100달러**로 걸어 둔다. 크레딧을 다 쓰면 카드로 넘어가지 않고 멈추게 → 월 예산 5만원 규칙 보호.
3. **API Keys → 새 키 만들기** (이름 예: `github-actions`). 키는 채팅·파일에 붙이지 말고 **GitHub 저장소 Settings → Secrets and variables → Actions → `ANTHROPIC_API_KEY`** 에 BK가 직접 넣는다. (저장소가 공개라 절대 파일에 쓰지 않음)
   - 넣으면 `api-check.yml`(하루 4번)이 키가 살아 있는지 자동 점검하고, 문제 있으면 텔레그램으로 알려 준다(이미 만들어 둠).

## 지금 구조와 크레딧이 들어갈 자리
- 지금 글·쇼츠 대본 같은 "글쓰기"는 대부분 **Claude 예약 작업(BK 구독 요금제)** 이 한다. 돈은 안 들지만 구독 사용량 한도를 같이 쓰고, 한도에 걸리면 그날 작업이 빠질 수 있다.
- API 크레딧은 **GitHub Actions 안에서 직접** Claude를 부를 수 있게 해 준다 → 예약 작업 실패에 덜 흔들리고, "한 번 더 검사" 같은 단계를 공짜에 가깝게 붙일 수 있다.
- `src/pipeline/shorts.py`는 이미 `ANTHROPIC_API_KEY`가 있으면 API로 문구를 쓰는 대안 경로가 있다(기본 모델 `claude-sonnet-5-5`).
- **못 하는 것:** Claude API는 이미지·영상 생성이 없다. Flow/Veo 클립, Higgsfield 등은 이 크레딧으로 결제 불가.

## 모델 가격 (1백만 토큰당, 2026-11 기준)
| 모델 | 입력 | 출력 | 쓰임 |
|---|---|---|---|
| Opus 5.5 (`claude-opus-5-5`) | $4 | $20 | 쇼츠 대본·글처럼 품질이 중요한 것 |
| Sonnet 5.5 (`claude-sonnet-5-5`) | $2 | $10 | 대량 손질, 일반 글 |
| Haiku 5.5 (`claude-haiku-5-5`) | $0.10 | $0.50 | 검사·분류(아주 쌈) |
- Batch API(몇 시간 안에 결과)면 **50% 할인**, 같은 규칙 문서를 반복해서 넣으면 프롬프트 캐싱으로 입력비가 크게 줄어든다.
- 감 잡기: 한글 1,000자 ≈ 토큰 1,000~1,500개.

## 추천 상위 3가지 (수익에 가까운 순)

### 1. 동전이 쇼츠 대본 "여러 안 + 채점" (Opus 5.5)
- 이틀에 1편 대본을 만들 때 훅·대본을 5~8안 쓰고, 별도 호출이 세계관 바이블·아하 규칙·첫 1초 훅 기준으로 채점해 상위 2안만 남긴다. BK는 고르기만.
- 왜: "1편 품질이 사이트 운명 좌우"(BK 11/19). 쇼츠는 지금 가장 큰 유입 통로.
- 비용: 1회 입력 2만·출력 1만 토큰 ≈ $0.28 → 월 15회 ≈ **$4~5**.

### 2. don3chon 기존 글 품질 손질 (Sonnet 5.5 + Batch)
- 색인된 글 ~100편을 하나씩: 첫 문단에 바로 답이 있는지, 숫자·출처가 사이트 데이터와 맞는지, 기계적 표현("결론적으로" 등), 얇은 부분을 찾아 **고친 안을 PR로** 올린다(자동 반영 아님, BK 확인 후).
- 왜: 애드센스 심사 중이라 "새 글 늘리기"보다 "있는 글 질 올리기"가 안전하고 승인·검색 순위에 직접 도움.
- 비용: 글당 입력 8천·출력 4천 토큰, 배치 50% ≈ $0.03 → 100편 한 바퀴 ≈ **$3**. 매달 한 바퀴 돌려도 충분.

### 3. 자동 글·쇼츠 올리기 전 "검사관" (Haiku 5.5)
- 매일 05:00 자동 글, 쇼츠 문구가 main에 올라가기 전에 GitHub Actions에서 한 번 더 검사: [광고] 표기 누락, IG/쇼츠/스레드에 제휴 링크·판매 문구, 개인사업자 정보 노출, 금지 표현, 사실과 다른 숫자. 걸리면 올리지 않고 텔레그램 알림.
- 왜: 공정위 표기·플랫폼 정책 위반 한 번이 채널·애드센스를 날릴 수 있음. 사람 손 안 대는 구조(BK 11/17)에 맞는 안전장치.
- 비용: 1회 ≈ $0.002 → 월 100회 넘어도 **$1 미만**.

### 합계와 여유
- 위 3가지 ≈ **월 $10 안팎**. 100달러의 10% 정도.
- 남는 크레딧 후보(우선순위 순, 하나씩 BK 확인 후):
  - 매일 자동 글을 예약 작업 대신 Actions + Opus 5.5로 옮겨 안정화 (월 ≈ $8). 애드센스 승인 후 하루 2편으로 늘릴 때 같이.
  - 월요일 KAMIS·오피넷 데이터에서 "아하 한 줄" 뽑기 → 장보기 카드·쇼츠 소재 (월 ≈ $1).
  - 5락실 게임 공략·영어 설명(Broken Sky EN 등) 손질 (한 번에 ≈ $2).
- 이 정도면 월 $20~25 수준이라 100달러 안에서 넉넉하다. 크레딧이 끊겨도 각 작업은 예약 작업 경로로 되돌릴 수 있게 만든다(지금 shorts.py처럼 "키 있으면 API, 없으면 기존 방식").

## 지키는 규칙
- 키는 GitHub Secrets에만. 코드·문서·채팅에 키 금지(공개 저장소).
- 만든 글·쇼츠에 공정위 대가성 표기, IG/쇼츠/스레드에 제휴 링크·판매 문구 금지 규칙 그대로.
- 콘솔 월 한도 100달러로 카드 결제 막기 → 월 예산 5만원 이하 유지.
- 새 자동화 코드 푸시·배포 전에는 BK 확인.
