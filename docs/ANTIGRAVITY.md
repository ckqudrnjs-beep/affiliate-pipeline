## 1. 넘겨받는 길
- BK는 다른 노트북에서 안티그래비티로 도구·게임을 만든다(우리 쪽에서 그 노트북에 직접 접근 불가).
- 완성본은 구글 드라이브 `G:\내 드라이브\어필라이트 수익화 관련 자료\antigravity\<사이트>\` 에 둔다. `<사이트>` = `don3chon` 또는 `5raksil`. 폴더마다 `index.html` + `README.md`.
- 실제 경로(2026-11-16 확인): 5락실 = `antigravity\5raksil\index.html`, 돈삼촌 = `antigravity\don3chon\index.html`. **같은 이름으로 덮어써서 올라오므로 받을 때 수정 시각으로 새 것인지 확인**하고, README.md 는 갱신 안 될 때가 있어 본문을 직접 읽는다.
- 그 노트북에 "Google Drive for desktop"이 깔려 있으면 안티그래비티에게 위 경로에 바로 저장하라고 하면 된다. 없으면 드라이브 웹에 올리거나 채팅에 첨부.
- 우리(Claude)는 BK 컴퓨터 연결이 끊겨 있어도 구글 드라이브 연결로 파일을 받을 수 있다.

## 2. 붙일 때 검사 (외부 코드로 취급)
1. 외부 스크립트·추적기·`fetch`·API 키·전송 코드 없는지. 글꼴(구글 폰트)만 허용.
2. 머리글·바닥글·메뉴는 버리고 사이트 틀(`site.py page()` / `playground/build.py` 게임 페이지)에 끼운다. CSS는 도구 이름 클래스 아래로 묶는다(사이트 `.receipt` 등과 충돌).
3. 돈삼촌: 제휴 링크·상품 카드·항상 켜진 [광고] 띠 넣지 않음(BK 전략 + 애드센스 심사). 계산기 링크만. 설명 글(사용법·개인정보·팁) 1,500자 이상, 색인·사이트맵 포함.
4. 5락실: `nr_bonus` 를 직접 쓰지 않는다. 코인·아이템은 `Bonus.played / setGitem / gitem / state` 만. 산 아이템은 `GAME_ITEMS`(own 키 `g:<slug>:<k>:<id>`) 로 — 다른 키는 프로필 동기화 때 지워진다. 별명은 `Profile.nick()`(자동 별명 `nr_nick` 는 "아바타 이름" 형식이 아님). game.js 에 `https://` 금지(빌드 검사). 공략 글 `guides/<slug>.md` 같이(AGENTS 0-9).
5. 사실과 다른 숫자(가짜 원본 용량, 과장 문구), 특정 브랜드 상품명 샘플은 고친다.
