## 1. 한 줄 소개
밤마다 도시 곳곳에 '균열'이 열리고, 그 안에서 기계 괴물이 쏟아진다. 사냥꾼이 되어 균열을 하나씩 닫아라.
콤보로 띄우고, 스킬로 끊고, 보스를 쓰러뜨려 장비를 얻는 10~15분짜리 한 판.

## 2. 세계관 (오리지널)
- 무대: 2099년 해안 도시 **'아르코'**. 지하 깊은 곳의 에너지 '루멘'이 새어 나오며 공간이 찢어진 곳 = **균열**.
- 균열 속에서는 버려진 기계들이 루멘을 먹고 괴물(**잔해체**)이 된다.
- 주인공 = 시청 소속 **균열 사냥꾼**. 의뢰판에서 균열을 골라 들어가고, 닫으면 보상.
- 톤: 어두운 네온 + 비 내리는 밤 + 따뜻한 조명. 잔인한 표현 없음(적은 부서져 빛 조각으로 흩어짐) → 전체이용가 목표.

## 3. 직업 2개 (체험판)
| | **섬광 검객 '진'** | **중력 파쇄자 '미르'** |
|---|---|---|
| 스타일 | 빠른 근접 연타·공중 콤보 | 느리지만 묵직한 범위·끌어당기기 |
| 무기 | 빛나는 단검 2자루(루멘 블레이드) | 중력 해머 |
| 기본 콤보 | 4타(베기·베기·올려베기·찌르기) | 3타(휘두르기·내려찍기·밀쳐내기) |
| 스킬 1 | 잔광 돌진: 앞으로 순간이동 베기 | 중력 우물: 주변 적을 한곳에 모음 |
| 스킬 2 | 초승달 올려베기: 띄우기 | 지진 강타: 바닥 충격파(넘어뜨림) |
| 스킬 3 | 회전 칼날: 공중에서도 사용 | 궤도 투척: 해머를 던졌다 되돌림 |
| 스킬 4 | 백섬: 3연속 이동 베기 | 반중력 띄우기: 큰 범위 띄움 |
| 필살기(게이지 100%) | **천 갈래 빛**: 화면 정지 연출 + 전체 베기 | **블랙 코어**: 작은 블랙홀로 빨아들인 뒤 폭발 |
| 난이도 | 쉬움(입문) | 보통 |

- 스킬 이름·연출은 자체 창작. 기존 게임 스킬명·커맨드표를 옮기지 않는다.

## 4. 전투·콤보 시스템
- 이동: 좌우 + 앞뒤(깊이 3단계 띠). 점프, 대시(좌우 두 번), 회피 구르기(무적 0.3초).
- 공격 버튼 1개(연타=콤보), 스킬 4칸 + 필살기 1칸. 키보드: 방향키/WASD, Z 공격, X 점프, C 대시, A·S·D·F 스킬, 스페이스 필살기.
- 모바일(가로 화면): 왼쪽 가상 스틱, 오른쪽 공격(큰 버튼)·점프·스킬 4·필살기. 버튼 크기·위치 설정 가능.
- **캔슬**: 기본 공격 → 스킬, 스킬 → 다른 스킬로 끊어 이어가기(콤보 맛의 핵심).
- **띄우기·공중 콤보**: 띄운 적을 공중에서 계속 때림. 같은 적을 오래 띄우면 점점 무거워짐(무한 콤보 방지).
- 판정 연출: 맞을 때 0.05초 멈춤(히트스톱), 화면 흔들림, 데미지 숫자, 콤보 수·'스타일 등급'(D→C→B→A→S).
- 자원: 기력(스킬 사용, 자동 회복) + 필살기 게이지(때리면 참).
- 방 클리어마다 평가(시간·콤보·피격 수) → S/A/B/C. 보상 상자 개수가 달라짐.

## 5. 체험판 던전: 버려진 7호선 기지
4개 방 + 보스방, 한 판 10~15분.
1. **승강장** — 졸개 '녹슨 정비병'(근접), '전선 드론'(공중·전기). 조작 익히기 안내.
2. **선로 터널** — 지나가는 유령 열차(피하기 장치), '방패 수리공'(정면 막기, 뒤에서 때려야 함).
3. **변전실** — 바닥 전기 장판 순환, 엘리트 '고압 정비반장'.
4. **화물 창고** — 상자 부수기(회복·재료), 몰려오는 웨이브 3회.
5. **보스: 궤도 포식자 '마그나 레일'** — 열차 칸들이 이어진 거대 기계 지네.
   - 1페이즈: 머리 돌진, 칸마다 포탑 사격(옆 칸 부수면 약해짐).
   - 2페이즈(체력 50%): 천장에 매달려 레일 레이저 낙하, 작은 칸 분리 소환.
   - 약점 '코어'가 열릴 때 띄우기 → 큰 피해. 패턴은 경고 표시 후 발동(억울한 즉사 없음).
- 난이도 3단계: 보통 / 어려움(체험판 클리어 후) / 악몽(매일 바뀌는 수식어: '적 속도+20%' 등, 오늘의 순위용).

## 6. 성장·장비
- 레벨 1~20(체험판). 레벨업마다 스탯 자동 + 스킬 포인트 1(스킬 강화 3단계).
- 장비 6칸: 무기·머리·상의·하의·장갑·장신구. 등급 일반(회색)·고급(초록)·희귀(파랑)·전설(주황).
- 세트 2종(예: '정비공의 유산' 3세트: 기력 회복+20%).
- 강화 +0~+10: 던전 재료로만 강화. **실패해도 장비가 사라지거나 내려가지 않음**(뽑기·도박 느낌 금지).
- 분해 → 재료. 거래·선물·현금화 없음.
- 저장: 기기(localStorage) + 5락실 프로필 코드가 있으면 서버(D1)에 동기화(다른 기기에서 이어하기).

## 7. 5락실 프로필·코인 연동 (꾸미기 전용)

## 8. 웹 성능 목표
- 2D 캔버스(WebGL 불필요) + 미리 그린 스프라이트(코드로 그린 그림을 시작할 때 오프스크린 캔버스에 구움).
- 첫 화면 페이지는 지금처럼 가볍게, 게임 본체는 **시작 버튼 누를 때** 불러옴. 본체 gzip 150KB 이하 목표.
- 60fps(중급 안드로이드 기준), 픽셀 비율 최대 2, 화면 픽셀 상한, 오브젝트 재사용(풀링), 화면 밖 적 업데이트 축소.
- 소리: 웹오디오 합성(효과음·배경음 모두 코드). 음원 파일 없음.
- 가로 전체화면(아이폰은 화면 꽉 찬 오버레이), 탭 전환 시 자동 멈춤.
