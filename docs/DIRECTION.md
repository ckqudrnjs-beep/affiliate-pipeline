# 지금 방향 (DIRECTION.md) — 모든 자동 작업의 기준

> 이 파일이 **유일한 기준**이다. 다른 문서·예약 작업 지시문·코드 주석과 다르면 **이 파일이 이긴다.**
> 결정이 바뀌면 ① 이 파일을 먼저 고치고 ② 맨 아래 '결정 기록'에 날짜와 BK 말을 남기고 ③ 그다음 코드·다른 문서를 맞춘다.
> 자동 작업(Actions·예약 작업·Claude API 작업)은 일을 시작하기 전에 자기 채널 칸을 읽는다. 이 파일에 없는 형식·채널·일정은 새로 만들지 않는다.
> 최종 갱신: 2026-11-20

## 0. 프로젝트 지침 (항상, 모든 작업)
BK가 정한 상시 규칙. 어떤 작업도 예외 없음. 세부 작업 규칙은 루트 [AGENTS.md](../AGENTS.md).
1. BK에게는 **한국어**로, 짧게, 단계별로, 주소는 전체 URL(https://…)로.
2. **코드·설정 푸시·배포 전에 BK 확인.** 예외는 BK가 미리 승인해 둔 자동 게시 작업(3장 표의 '자동 승인' 표시)뿐.
3. **비밀번호·API 키는 채팅·파일·커밋·로그에 평문 금지.** 키는 BK가 GitHub Secret 에 직접 넣는다. 저장소는 공개(PUBLIC).
4. **공정위 대가성 표기·플랫폼 정책 준수.** 스팸·어뷰징·약관 위반 자동화, 비공식 봇·매크로 금지. 제휴 링크 숨기기(클로킹) 금지.
5. 인스타·스레드·쇼츠에는 판매·특가·제휴 문구와 제휴 링크를 넣지 않는다.
6. 개인사업자 정보는 어디에도 노출하지 않는다.
7. **계획·지침 MD(이 파일, PLAN, AGENTS 등)는 결정·변경이 생기면 지시 없이 그 자리에서 갱신**하고 날짜를 남긴다.
8. 확인 안 된 숫자·정책은 지어내지 않고 "확인 필요"로 표시.

## 1. 큰 목표와 바뀌지 않는 원칙

- BK 손 쓰는 시간 최소화, 완전 자동 우선, 묻는 횟수 줄이기 (BK 11/17). 예산 월 5만 원 이하, 주 10시간 이하.

## 2. 채널별 지금 형식

### 2-1. 돈삼촌 사이트 (don3chon.com)
- 범위: "주부 살림 돈" 안에서만 깊게. **새 카테고리 추가 금지** (BK 11/17). 새 도구도 같은 주제, 쇼츠 소재가 되는 것만.
- 글: 하루 1편 자동(애드센스 검토 중). 승인 뒤 하루 2편. 오후 글 작업은 승인 전까지 꺼 둠.
- 상품: 알리 상품 화·금 최대 3개 자동. [광고] 띠는 제휴 상품이 있는 페이지에만. 상품 목록은 /items (noindex).
- 레시피 20개에서 멈춤. 얇은 페이지는 noindex. 제휴 링크 숨기기(클로킹) 금지.
- 레시피 재료 쿠팡 링크: BK 손 링크가 먼저, 빈 재료만 쿠팡 Open API 검색으로 파트너스 링크 자동(이름이 맞는 상품만). **애드센스 심사 중엔 사이트 반영 안 함(시험 실행만), 승인 뒤 주 1회 켬** (BK 11/20). 사이트엔 재료 이름 + "쿠팡에서 보기"만(가격·이미지 안 실음), [광고] 대가성 문구 그대로. 장보기 리스트·쇼츠·인스타·스레드엔 제휴 링크 없음 (쿠팡 최종 승인 11/20).

### 2-2. 5락실 (5raksil.com)
- 코인은 무료로만 얻음(현금·거래·뽑기 판매 금지). 새 게임 = 같은 PR에 스킨·공략 글·포스터 (AGENTS.md 7~10).
- 관리자·게시판·프로필 페이지에는 광고 없음.
- 5락실 쇼츠: 밸런스게임 쇼츠 매일 17:00 공개(품질 게이트 미달인 날은 쉼), 밸런스 질문 매일 자동 추가.
- **반복 양산 금지(5락실)**: 직전 3편과 위쪽 띠 흰 줄(같은 말)·배경 색 테마가 겹치지 않게. 배경 4가지 테마는 날마다 돌림, 띠는 후보·문구 은행에서 직전 3편과 같은 것 제외, BGM 4곡은 날마다 돌림 (BK 11/20 "비슷한 틀로 찍어낸 영상이 걸러내는거라면").
- 5락실 쇼츠 BGM: BK Suno 4곡 돌려 쓰기(합성 베이스 대신), 장면 전환을 박자에 맞춤. 몽글이 밈은 자체 음악이라 BGM 없음 (BK 11/20). 기준 docs/BGM.md.
- 5락실 쇼츠 화면(BK 11/20 분야 잘 된 쇼츠 패턴): 위쪽 검은 띠 두 줄 제목(흰 = 보는 사람에게 거는 도전, 노랑 = 무엇인지, 주아체) 처음부터 반응 컷까지 → 번호(A/B) 선택지 → 3·2·1 → 반전(실제 투표 20표 이상이면 % 막대, 아니면 몽글이의 선택) → 'B를 고른 나:' 몽글이 반응 컷. 띠·제목에 숫자 통계("한국인 99%", "상위 10%")·지능 비하 금지(가짜 통계). 게임 쇼츠도 띠(흰 = 도전 후킹, 노랑 = 게임 이름).
- **품질 게이트(5락실 밸런스·게임 쇼츠, BK 11/20 밤 "품질이 떨어지는 문구 그리고 영상과 구도는 안하느니 못해")**: 렌더 전에 편집장(Claude Sonnet) 채점 — 결 넷(뻔하지 않음·인사이트·여운·한없이 즐거움) 중 최고 + 중독성 + 문구 + 구도, 40점 만점에 32점(평균 8) 이상이고 한 칸도 6 미만이 없어야 통과(삼촌 48/60 과 같은 80% 선). 구도는 코드로도 검사(선택지 글자가 그 형식 칸에 56px 이상으로 들어가야 함, 안 되면 그 형식 제외). 밸런스: 미달이면 지적을 넣어 다시 짜고, 문구는 괜찮은데 질문이 약하면 그날 다른 질문으로, 채점 최대 3번. 다 미달이면 그날은 올리지 않고 텔레그램 알림, 기록에 '쉼'(형식·띠 반복 검사에서는 빠짐). 게임: 띠 흰 줄 후킹을 바꿔 최대 3번, 미달이면 쉬고 알림(기록 안 함 → 다음 차례에 다시). 채점이 안 되는 날(키·예산·네트워크)은 구도·화면 검사만으로 진행. 코드 `raksil_shorts.GATE_*`, `raksil_games.gate`.
- **형식 돌리기(5락실 밸런스 쇼츠, BK 11/20 "네 바꿔야돼요")**: 매일 같은 틀에 질문만 바뀌면 반복·양산으로 보일 수 있어 화면 구성이 다른 5가지 형식을 5일 한 바퀴로 돌린다(11/21 시작): ① 몽글이 갈림길(화면 좌우 분할, 몽글이가 양쪽 기웃 → 한쪽으로 뛰어감) ② 스피드 3연속(그날 질문 3개 2초대씩 + 줄어드는 시간 막대, 끝 'AAB 처럼 댓글로') ③ 몽글이 vs 너(몽글이가 먼저 고른 뒤집힌 카드 → 3·2·1 → 뒤집기 → '같으면 찌찌뽕') ④ 어제 결과 → 오늘(전광판에 어제 질문: 실제 20표 이상이면 % 막대, 아니면 몽글이 선택만 → 휙 → 오늘 질문 나란히 → '결과는 내일 발표') ⑤ 3초 선택(기존 위아래 칸 + 3·2·1 + 반전 + 'B를 고른 나:'). 조건(몽글이 선택·질문 3개·어제 기록)이 안 되면 다음 형식, 직전 3편과 같은 형식은 건너뜀. 제목 띠·엔딩·BGM 돌림·가짜 통계 금지·약 10초는 모든 형식 공통. 3연속 편 댓글은 다음 날 A/B 투표로 안 셈. 강제 시험: 환경변수 RAKSIL_FORMAT. 코드 `raksil_shorts.FORMATS`.
- **몽글이 기억·연쇄 질문 (BK 11/20 '빌드업')**: 몽글이의 선택을 업로드 기록에 남기고, 다음 편 몽글이가 지난 5번 선택을 읽어 성격이 이어지게(같은 이유 반복 금지, 가끔 지난 선택 받아치기). 질문 예약(21:37)은 이틀에 한 번 어제 질문의 '2탄'(어제 고른 쪽을 전제로 한 다음 갈림길)을 낸다. **주간 시리즈 '몽글이의 한 주'**: 월요일마다 그 주 테마 하나(예: 겨울 먹거리 주간)를 정해 7일 질문을 그 테마로. **댓글 투표**: 어제 쇼츠 공개 댓글을 읽기만 해서 Claude 가 A/B 로 세고 사이트 투표와 합쳐 20표 이상이면 실제 % 막대(설명란 '댓글로 A / B 남기면 내일 결과에 같이 세요'). 11/21(토) 17:00 편부터 (BK 11/20 "토요일부터 적용해줘", "오락실 쇼츠도 기획 반영해줘"). 세부 docs/5RAKSIL_PROMO.md.
- 5락실 쇼츠 엔딩에 사이트 주소 5raksil.com 을 화면 글자로 넣는다(링크·스티커 아님) (BK 11/20 "쇼츠 상 홈페이지 주소를 넣으면").
- 홍보 이미지(썸네일·가로 포스터·인스타 계산기 카드): 어두운 그라데이션 + 두 줄 제목(한 단어 기울임 강조) + 실제 화면 폰 목업, 주아. 세부 docs/PROMO_DESIGN.md (BK 11/20 "가자", 도구는 홍보 이미지 스레드 PR에서 들어옴). 사이트 안 게임 포스터·레이아웃은 애드센스 승인 전까지 그대로. 새 게임만 썸네일 자동, 옛 게임은 안 만듦 (BK 11/20).

### 2-3. 삼촌 유튜브 쇼츠 (@don3chon)
- **형식: 동전이 캐릭터 영상이 기본, 주말 공개 편은 실사 삼촌 특별편(주 1회)** (BK 11/20 "오늘 올라가는 것부터 캐릭터를 만들어서 영상으로 하고 삼촌은 특별편으로 한번 나오고").
  - **특별편도 첫 3초(1번 컷)·썸네일은 동전이 만화, 실사 삼촌은 2번 컷부터.** 모든 편 첫 1~3초에 AI 실사 얼굴 금지. 같은 영상 지우고 다시 올리기 금지(고칠 게 생기면 그 편은 건너뜀) (BK 11/20 카드 "만화로 시작, 삼촌은 중간에" — 실사 얼굴로 시작한 11/18 8회·11/19 11회·HeyGen 17회 vs 만화·카드 시작 300~1,200회).

- **돈을 강조하지 않는다 (BK 11/20 밤, 최우선)**: "동전 날아가는 것·돈이 샌다 표현은 하지 말고 돈돈돈 강조할 필요 없어", "뻔한 기획 구성은 빼야". 금화·저금통·'새는 돈' 그림과 말 금지, '문제 → 이렇게 바꾸면 아낀다' 정보형 구성 금지. 동전이가 겪는 상황·이야기가 중심, 살림 팁은 마지막 한 줄. 숫자 상자는 '인사이트' 편에서 꼭 필요할 때만.
- **편마다 결 하나 + 중독성 (BK 11/20 밤)**: "뻔한 것이 없는 것, 아니면 인사이트를 주는 것, 사람들의 여운에 남는 것, 어쩔 때는 한없이 즐거운 것", "그리고 중독성". `toon` 이 공개일로 결을 돌려 정하고(mood), 채점 fun 에 결 + 중독성(반복 개그·다시 보게 되는 끝 컷·끝-처음 루프·귀에 남는 소리), clarity 에 문구 품질을 넣음.

## 4. 수정 → 반영 → 배포 흐름
결정 하나가 들어오면 이 순서로만 움직인다. 순서를 건너뛰면 어긋남이 생긴다.

1. **결정 받기**: BK 말이 스레드에 남는다. 그 영역 **담당 스레드**가 받는다(3장). 다른 영역이면 그 담당 스레드에 알린다(직접 고치지 않음).
2. **기준에 적기**: 이 파일의 해당 칸을 고치고 맨 아래 결정 기록에 날짜 + BK 말 한 줄. 꺼지는 것은 '꺼진 것'에, 기계가 볼 값은 7장 JSON에.
3. **아래로 맞추기**: 세부 규칙 문서 → 코드 → 예약 작업 지시문 순서. **옛 규칙은 지운다**(위에 날짜로 덧칠하지 않음). 예약 작업 지시문은 "DIRECTION 과 ○○.md 를 읽고 따른다" 수준으로 짧게 두고, 세부는 저장소 문서에만 쓴다.
4. **검사**: 테스트 전체(`PYTHONPATH=src python -m unittest discover -s tests`, 여기 `test_direction` 포함) 통과.
5. **BK 확인 → 푸시·PR·병합**: 지침 0-2. 같은 영역 PR 은 한 번에 하나.
6. **반영 확인**: 병합 뒤 다음 실행 결과를 담당 스레드가 한 번 본다. 매일 07:50 정합성 점검(`consistency`)이 어긋나면 텔레그램 한 줄.
7. **사본 맞추기**: 병합 뒤 바뀐 문서를 프로젝트 폴더 plan/ 에 복사(덮어쓰기 전 .bak). 원본은 언제나 저장소 docs/.
