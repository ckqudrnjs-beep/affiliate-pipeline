새 형식을 만들 때 판정 규칙:
1. 목소리가 없는 형식 → BGM 이 주인공(크게, 박자에 맞춰 편집).
2. 목소리가 있는 형식 → 낮게 깔고 목소리 나올 때 자동으로 낮춤.
3. 음악 변화 자체가 내용이거나, 게임·생활 소리(ASMR)가 훅인 형식 → 넣지 않음.
4. 유행 음원·남의 곡은 쓰지 않는다(저작권). Suno 로 BK가 만든 곡만.

## 3. 돌려 쓰기
- 날짜로 정해지는 순번(기록 파일 없음). 같은 종류의 연속 편은 늘 다른 곡이고, 4편마다 한 바퀴.
- 같은 날 5락실 밸런스와 게임 쇼츠는 서로 다른 곡.
- 한 바퀴 돌면 같은 곡도 다른 부분(마디에 맞춘 시작 후보)에서 시작.
- 삼촌 만화 spec 에 `"bgm": "곡이름"` 으로 고정, `"bgm": false` 로 끌 수 있음(삼촌 곡이 다시 들어오면 쓰임).

## 4. 박자에 맞춘 편집 (BK 11/20 "노래 BPM에 맞춰서 쇼츠 구성 속도를 맞춰야")
영상 0초 = 곡의 마디 시작. 그래서 영상 안 박자는 0, 1박, 2박 … 이다.
- **삼촌 만화**(tools/toon_assemble.py): 곡이 있을 때만 컷 길이·끝 멈춤·엔딩 길이 = 박 단위, 숫자 등장·효과음 = 반 박. 지금은 곡이 없어 예전과 같음.
- **5락실 밸런스**: 질문 → 3,2,1 → 반전 전환을 박에 맞춤, 3·2·1 숫자 하나 = 1~2박.
- **5락실 게임·사격장**: 플레이 → 안내 화면 전환을 박에 맞춤.
- **삼촌 실사·대체 영상**: (곡이 생기면) 말 속도가 우선이라 박자 편집 없이 낮게만 깐다.
- 대본·클립을 만들 때 참고: 100 BPM 이면 1박 0.6초, 한 마디 2.4초. 컷 하나는 2~4마디가 보기 좋다.

## 5. 소리 처리
- 영상 길이에 맞춰 자르고 0.3초 페이드인, 1.2초 페이드아웃(엔딩까지 이어짐).
- 음량은 곡마다 측정값(LUFS)으로 맞춘 뒤, 목소리·효과음이 나오면 사이드체인으로 약 5~10dB 자동 낮춤.
- 영상은 다시 인코딩하지 않고 소리만 바꾼다.

## 6. 라이선스
- **확인됨 (2026-11-20)**: BK의 Suno 현재 요금제 = **Pro (Commercial use rights 포함)**. 이 기간에 만든 곡은 수익 채널에 써도 된다. Pro 는 월 다운로드 20곡 제한이 있으니 곡 추가는 한 달에 몇 곡씩.
- 이 곡들을 음원 유통사·Content ID 에 등록하지 않는다(우리 쇼츠가 저작권 신고를 받게 됨).

## 6-1. 삼촌용 새 곡 (BK 11/20 "삼촌 쇼츠에 맞는 것 은은하게 깔리는 것으로 제작")
지금 4곡은 '탐정·미션·반전' 느낌이라 동전이의 귀여운 표정과 부딪힘. 새 곡은 **뒤에 은은하게 깔리는 배경**이 목표:
- 분위기: 따뜻하고 포근한 집 안 오후. 어쿠스틱 기타 뜯기·부드러운 피아노·작은 우쿨렐레. 드럼 거의 없음, 멜로디는 단순하게 반복.
- 빠르기 80~95 BPM, 장조, 가사 없음, 긴 전주 없음, 갑자기 커지는 부분 없음.
- 높은 종소리·벨·실로폰은 빼기(효과음 '톡'과 부딪힘).
- 섞을 때: -27 LUFS 정도로 아주 낮게(5락실보다 더 작게), 박자 편집은 그대로 적용.
- Suno 프롬프트(Instrumental 켜고):
  1. `warm cozy home background music, soft fingerpicked acoustic guitar, gentle felt piano, light ukulele, no drums, calm and cute, 88 bpm, major key, simple repeating melody, lo-fi warmth, no bells, instrumental`
  2. `gentle heartwarming cartoon puppy background, soft pizzicato strings and muted piano, very light brushes, 92 bpm, major key, playful but calm, steady loudness, no glockenspiel, instrumental`
  3. `soft afternoon kitchen music, mellow acoustic guitar and soft rhodes, warm and tender, 84 bpm, simple loop, no vocals, no build-up, no bells`
- 2~3곡 받으면: 김치찌개 편에 깔아 BK 확인 → OK 곡만 media/bgm/uncle/ 에 넣고 config/bgm.json kinds 에 toon 을 다시 넣는다.

## 6-2. 효과음 (BK 11/20 "쇼츠에 띵 소리가 이질감")
- 삼촌 만화의 '띵'(2600Hz 쇳소리) → 낮고 짧은 '톡'으로 바꿈(tools/toon_assemble.py SFX). 철퍼덕(flop)도 조금 작게.
- spec 에 `"sfx": "none"` 이면 효과음을 전부 뺀다(은은한 BGM 이 들어온 뒤 비교용).

## 7. 곡 추가·교체
1. mp3 를 `media/bgm/<uncle|raksil>/<영문-이름>.mp3` 로 넣는다(128kbps).
2. BPM·첫 마디(bar0)·시작 후보(starts)·LUFS 를 분석해 `config/bgm.json` tracks 에 넣고, kinds 의 order 에 이름을 넣는다.
3. 이 문서 2장 표에 한 줄. `tests/test_bgm.py` 통과.
